# SCSS 函数（@function 与内置模块）

> 📖 官方文档：[Sass @function](https://sass-lang.com/documentation/at-rules/function/)
>
> 📖 官方文档：[Sass 内置模块总览](https://sass-lang.com/documentation/modules/)

### 一、概述

SCSS 的函数分三类：

1. **自定义函数**：用 `@function` 定义，接收参数、用 `@return` 返回值——适合封装常用计算（如 px 转 rem、透明度计算）
2. **内置模块函数**：官方提供的工具函数库（`sass:math`、`sass:string` 等），需 `@use` 引入
3. **纯 CSS 函数**：`calc()`、`var()` 等，Sass 原样输出，交给浏览器计算

**函数 vs mixin 的本质区别：函数返回"值"，mixin 输出"样式"。**

### 二、自定义函数

#### 1. 基本语法

```scss
@use "sass:list";

// @function 名字(参数...) { ... @return 返回值; }
@function fibonacci($n) {
  $sequence: 0 1;
  @for $_ from 1 through $n {
    $new: list.nth($sequence, list.length($sequence)) + list.nth($sequence, list.length($sequence) - 1);
    $sequence: list.append($sequence, $new);
  }
  @return list.nth($sequence, list.length($sequence));
}

.sidebar {
  margin-left: fibonacci(4) * 1px; // 像普通 CSS 函数一样调用
}
```

要点：

- 函数体内**必须有 `@return`**，遇到 `@return` 立即结束并返回
- 调用语法与 CSS 函数一致：`函数名(实参)`
- 函数体内只能写"通用语句"（变量声明、流程控制、`@debug/@warn/@error`），**不能写属性声明和嵌套规则**
- 函数名 `-` 与 `_` 等价；不能以 `--` 开头

> ⚠️ **注意：** 官方强烈不建议在函数里产生副作用（改全局变量等）。**需要副作用用 mixin，函数只做纯计算。**

#### 2. 参数：默认值、关键字参数、可变参数

与 mixin 完全一致的参数机制：

```scss
@use "sass:color";

// 默认值参数示例：计算补色再按比例混合
@function muted-invert($color, $amount: 100%) {
  @return color.mix(color.complement($color), $color, $amount);
}

.header {
  background-color: muted-invert(#036, 80%);      // 位置传参
  color: muted-invert(#036, $amount: 80%);        // 关键字传参
}

// 可变参数
@function sum($numbers...) {
  $sum: 0;
  @each $number in $numbers {
    $sum: $sum + $number;
  }
  @return $sum;
}

.micro { width: sum(50px, 30px, 100px); } // 180px
```

#### 3. 提前返回（early return）

处理边界情况时提前 `@return`，比层层嵌套 `@else` 清晰：

```scss
@use "sass:string";

@function str-insert($string, $insert, $index) {
  @if string.length($string) == 0 {
    @return $insert; // 空字符串直接返回，避免无谓计算
  }
  $before: string.slice($string, 0, $index);
  $after: string.slice($string, $index);
  @return $before + $insert + $after;
}
```

#### 4. 实战示例：px 转 rem

```scss
// 基准字号 16px，把 px 值转成 rem
@use "sass:math";

$base-font-size: 16px !default;

@function px-to-rem($px) {
  @return math.div($px, $base-font-size) * 1rem;
}

.title {
  font-size: px-to-rem(24px); // 1.5rem
}
```

#### 5. 与纯 CSS 函数同名怎么办

自定义函数名尽量加前缀避免与 CSS 函数撞名（如 `rgb`、`min`、`max` 都是 CSS 函数）。一旦定义了同名 Sass 函数，Sass 会优先用你的，可能破坏预期行为。

### 三、运算符

函数与表达式中可用的运算符（优先级从高到低）：

1. 一元运算符：`not`、`+`、`-`、`/`
2. `*`、`/`、`%`
3. `+`、`-`
4. `>`、`>=`、`<`、`<=`
5. `==`、`!=`
6. `and`、`or`

```scss
@debug 1 + 2 * 3;        // 7
@debug (1 + 2) * 3;      // 9（括号改变优先级）
@debug 10px + 4px;       // 14px（带单位运算）
@debug 1in + 6px;        // 102px（兼容单位自动换算）
@debug "Helvetica" + " Neue"; // "Helvetica Neue"（字符串拼接）
@debug 5 > 3 and 2 < 1;  // false
```

> ⚠️ **注意（重要变更）：** `/` 作为除法**已废弃**。`font-size: $size / 2` 在新版 Sass 会输出警告并保留原样，**必须用 `math.div($size, 2)`**。

```scss
@use "sass:math";

.half { width: math.div(100px, 2); } // 50px ✅
.old  { width: 100px / 2; }          // ⚠️ 废弃写法
```

> ⚠️ **注意：** 颜色之间的算术运算（`#010203 + #040506` 按通道相加）同样已废弃，改用 `sass:color` 的函数。

### 四、内置模块速查

内置模块以 `sass:` 开头，用 `@use` 引入后通过命名空间调用：

```scss
@use "sass:math";
@use "sass:color";

.button {
  width: math.div(100px, 3);                      // 数学计算
  border-color: color.scale(#6b717f, $lightness: 20%); // 颜色处理
}
```

> ⚠️ **注意：** 模块系统之前所有内置函数是全局可用的（如 `darken()`、`nth()`、`map-get()`）。这些全局别名**官方已不推荐**，新代码统一走模块（`color.adjust()`、`list.nth()`、`map.get()`）。

#### 1. `sass:math` —— 数学

| 函数/变量 | 作用 | 示例 |
| --- | --- | --- |
| `math.div($a, $b)` | 除法（替代 `/`） | `math.div(10, 4)` → `2.5` |
| `math.percentage($n)` | 小数转百分比 | `math.percentage(0.5)` → `50%` |
| `math.round / ceil / floor / abs` | 四舍五入/向上/向下取整/绝对值 | `math.ceil(4.2)` → `5` |
| `math.max / min` | 最值（需兼容单位） | `math.max(1px, 10px)` → `10px` |
| `math.clamp($min, $n, $max)` | 限定区间 | `math.clamp(0, 5, 3)` → `3` |
| `math.random($limit)` | 随机数 | `math.random(10)` → 1~10 整数 |
| `math.pow / sqrt / hypot` | 幂/平方根/ | `math.pow(2, 10)` → `1024` |
| `math.sin / cos / tan / log` | 三角/对数 | 参数需兼容 `deg` |
| `math.unit($n)` | 取单位 | `math.unit(16px)` → `"px"` |
| `math.is-unitless($n)` | 是否无单位 | `math.is-unitless(100)` → `true` |
| `math.comparable($a, $b)` | 单位是否可运算 | `math.comparable(10cm, 3mm)` → `true` |
| `math.$pi` | 圆周率 | `3.1415926536` |

#### 2. `sass:color` —— 颜色

| 函数 | 作用 |
| --- | --- |
| `color.adjust($color, $key: 值)` | **按增量**调整：`color.adjust(#6b717f, $red: 15)` |
| `color.scale($color, $key: %)` | **按比例**调整：`color.scale(#6b717f, $lightness: 20%)` |
| `color.change($color, $key: 值)` | **直接设置**通道：`color.change(#6b717f, $red: 100)` |
| `color.mix($c1, $c2, $weight)` | 混色 |
| `color.complement($color)` | 补色 |
| `color.invert($color)` | 反色 |
| `color.grayscale($color)` | 灰度 |
| `color.channel($color, "hue")` | 读取通道值 |
| `color.red / green / blue / hue / saturation / lightness / alpha` | 读单通道 |
| `color.ie-hex-str($color)` | 转 IE 的 `#AARRGGBB` 格式 |

```scss
@use "sass:color";

// 三兄弟的区别
$base: #6b717f;
color.adjust($base, $lightness: 15%); // 亮度 +15 个百分点
color.scale($base, $lightness: 15%);  // 亮度向 100% 方向缩放 15%
color.change($base, $lightness: 15%); // 亮度直接设为 15%
```

> ⚠️ **注意：** 老代码里的 `lighten()`、`darken()`、`opacify()` 等全局函数是 `color.adjust` 的旧别名，已被官方标记废弃，统一改用 `color.adjust()` / `color.scale()`。

#### 3. `sass:string` —— 字符串

| 函数 | 作用 | 示例 |
| --- | --- | --- |
| `string.quote / unquote` | 加/去引号 | `string.quote(hel lo)` → `"hel lo"` |
| `string.to-upper-case / to-lower-case` | 大小写转换 | |
| `string.length($s)` | 长度 | `string.length("hello")` → `5` |
| `string.index($s, $sub)` | 子串位置（1 起，找不到返回 null） | `string.index("hello", "l")` → `3` |
| `string.slice($s, $start, $end)` | 截取（支持负索引） | `string.slice("hello", 2, 4)` → `"ell"` |
| `string.insert($s, $insert, $index)` | 插入 | |
| `string.split($s, $sep)` | 分割成 list | `string.split("a,b", ",")` |
| `string.unique-id()` | 生成唯一 id | 动态命名动画时有用 |

#### 4. `sass:list` —— 列表

| 函数 | 作用 |
| --- | --- |
| `list.length($list)` | 长度 |
| `list.nth($list, $n)` | 取第 n 项（**索引从 1 起**，支持 `-1` 表末尾） |
| `list.index($list, $val)` | 查找值的索引（找不到返回 null） |
| `list.append($list, $val, $sep)` | 返回追加了元素的新列表 |
| `list.join($l1, $l2)` | 拼接 |
| `list.set-nth($list, $n, $val)` | 替换第 n 项，返回新列表 |
| `list.zip($l1, $l2)` | 按位组合成嵌套列表 |
| `list.is-bracketed($list)` | 是否方括号列表 |
| `list.separator($list)` | 分隔符（space/comma/slash） |
| `list.slash($a, $b)` | 构造斜杠分隔列表 |

> ⚠️ **注意：** 列表索引**从 1 开始**，不是 0；`-1` 指最后一项。列表同样不可变——`append` 等返回新列表。

#### 5. `sass:map` —— 映射

详见 [07-映射(Map)](./07-映射%28Map%29.md)。

#### 6. `sass:meta` —— 元信息

| 函数 | 作用 |
| --- | --- |
| `meta.type-of($val)` | 类型：`number/string/color/list/map/bool/null/function/arglist/calculation` |
| `meta.inspect($val)` | 任何值的字符串表示（调试利器） |
| `meta.keywords($args)` | 收集可变参数中的关键字参数成 map |
| `meta.variable-exists / global-variable-exists` | 变量是否存在 |
| `meta.function-exists / mixin-exists` | 函数/mixin 是否存在 |
| `meta.feature-exists($name)` | Sass 特性检测 |
| `meta.call($fn, $args...)` | 动态调用函数（配合 `meta.get-function`） |
| `meta.load-css($url)` | 运行时加载 CSS（替代嵌套 `@import`） |

```scss
@use "sass:meta";

@debug meta.type-of(16px);  // number
@debug meta.type-of("hi");  // string
@debug meta.type-of(red);   // color
```

#### 7. `sass:selector` —— 选择器

提供 `selector.unify()`、`selector.extend()`、`selector.parse()` 等函数，用于操作选择器本身，配合 `&` 和 `@at-root` 使用，属高级用法。

### 五、纯 CSS 函数（Sass 不干预）

`calc()`、`var()`、`url()`、`rgb()`（传变量参数时）等函数 Sass **原样输出**，由浏览器运行时计算：

```scss
:root { --gap: 16px; }

.item {
  width: calc(100% - var(--gap)); // 原样输出，浏览器计算
}
```

可以在 `calc()` 内混用 Sass 表达式（编译期部分会先算好）：

```scss
$gap: 16px;

.item {
  width: calc(100% - #{$gap}); // 编译成 calc(100% - 16px)
}
```

### 六、常见问题与注意事项

1. **函数必须以 `@return` 结束**，所有分支都要能走到 `@return`，否则报错。
2. **`/` 不是除法了**：一律 `math.div()`；`%` 是取余不是百分比拼接。
3. **类型检查**：函数开头可用 `meta.type-of()` 校验参数类型，配 `@error` 快速失败。
4. **递归**：Sass 函数支持递归调用，但深度递归会拖慢编译甚至栈溢出。
5. **函数不能输出样式**：写属性声明会报错，要输出样式用 mixin。

### 七、总结

- `@function` 定义计算逻辑、`@return` 返回值、参数机制与 mixin 一致
- 内置工具集中在 7 大模块：math、color、string、list、map、meta、selector，统一 `@use` 引入
- 新代码禁用全局旧函数（`darken()`、`map-get()`…）和 `/` 除法、颜色算术
- 函数算"值"，mixin 出"样式"，纯 CSS 函数（`calc`/`var`）留给浏览器

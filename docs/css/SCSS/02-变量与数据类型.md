# SCSS 变量与数据类型

> 📖 官方文档：[Sass Variables](https://sass-lang.com/documentation/variables/)
>
> 📖 官方文档：[Sass Values](https://sass-lang.com/documentation/values/)

### 一、概述

**变量是 SCSS 最常用、最基础的能力**：把值起个名字，然后在整份样式表里复用。改主题色时只改一处，全部跟着变——这是纯 CSS 做不到（或者做起来很啰嗦）的事。

SassScript（SCSS 的表达式语言）支持 7 种数据类型：

| 类型 | 示例 | 说明 |
| --- | --- | --- |
| 数字（Number） | `1`、`16px`、`10%` | 数值可带单位可不带 |
| 字符串（String） | `"foo"`、`'bar'`、`baz` | 引号可有可无 |
| 颜色（Color） | `#fff`、`red`、`rgb(0,0,0)`、`hsl(0,100%,50%)` | |
| 布尔值（Boolean） | `true`、`false` | |
| 空值（Null） | `null` | 表示"没有值" |
| 列表（List） | `1px 2px 3px 4px`、`Arial, sans-serif` | 用空格或逗号分隔的序列 |
| 映射（Map） | `("key": value)` | 键值对集合，详见 [07-映射(Map)](./07-映射%28Map%29.md) |

### 二、变量的基本用法

#### 1. 声明与使用

变量名以 `$` 开头，声明语法和 CSS 属性声明很像：

```scss
$base-color: #c6538c;                  // 声明一个全局变量
$border-dark: rgba($base-color, 0.88); // 变量可以用在表达式中

.alert {
  border: 1px solid $border-dark;      // 使用变量
}
```

编译结果：

```css
.alert {
  border: 1px solid rgba(198, 83, 140, 0.88);
}
```

> 💡 **提示：** 和所有 Sass 标识符一样，变量名中的连字符 `-` 和下划线 `_` 等价，`$font-size` 和 `$font_size` 是同一个变量。

#### 2. 变量是"编译期"的

Sass 变量在编译完成后就消失了，输出的是**计算后的字面值**：

```scss
$variable: value1;

.rule-1 {
  value: $variable; // 编译为 value1
}

$variable: value2; // 中途改值

.rule-2 {
  value: $variable; // 编译为 value2（只影响之后的引用）
}
```

这一点与 CSS 自定义属性（CSS 变量）**本质不同**，见下文对比。

### 三、作用域

#### 1. 全局作用域与局部作用域

- 在文件**顶层**声明的变量是**全局变量**，声明之后在整个模块内都能访问
- 在**代码块内**（花括号里）声明的变量是**局部变量**，只在所在块内可用

```scss
$global-variable: global value;

.content {
  $local-variable: local value;
  global: $global-variable; // ✅ 可以访问全局变量
  local: $local-variable;   // ✅ 可以访问局部变量
}

.sidebar {
  global: $global-variable;  // ✅
  // local: $local-variable; // ❌ 错误：$local-variable 不在作用域内
}
```

#### 2. 遮蔽（Shadowing）

局部变量可以和全局变量**同名**，此时它们是两个独立的变量——局部作用域内用的是局部那个，全局的不会被意外改动：

```scss
$variable: global value;

.content {
  $variable: local value; // 新建了一个同名局部变量
  value: $variable;       // local value
}

.sidebar {
  value: $variable;       // global value（不受影响）
}
```

#### 3. `!global` 标志

如果确实需要在局部作用域内**修改全局变量**（常用于 mixin 里），加 `!global`：

```scss
$variable: first global value;

.content {
  $variable: second global value !global; // 赋值给全局变量
  value: $variable;
}

.sidebar {
  value: $variable; // second global value
}
```

> ⚠️ **注意：** `!global` **只能给已存在的全局变量赋值**，不能用它声明新的全局变量（Dart Sass 2.0 起强制如此，旧版本允许是已废弃行为）。

#### 4. 流程控制中的作用域（易错点）

在 `@if` / `@each` / `@for` / `@while` 里给**已存在**的同名变量赋值，不会遮蔽，而是直接修改外层变量：

```scss
@use "sass:color";

$dark-theme: true !default;
$primary-color: #f8bbd0 !default;

@if $dark-theme {
  // 这里不是新建局部变量，而是修改外层的 $primary-color
  $primary-color: color.adjust($primary-color, $lightness: -60%);
}

.button {
  background-color: $primary-color; // 用的是修改后的值
}
```

> ⚠️ **注意：** 但在流程控制里**新声明**的变量出了块就访问不到。想"先在循环里赋值、循环外使用"，必须**先在外层声明**（哪怕初始值是 `null`）。

### 四、`!default` 默认值

`!default` 的含义：**"如果这个变量还没定义（或值为 `null`），就用这个值；否则保留原值"**。

```scss
$primary-color: blue !default; // 若之前没定义过 $primary-color，它就是 blue

$primary-color: red;
$primary-color: blue !default; // 之前已定义为 red，所以仍是 red
```

两大用途：

1. **写可配置的主题库**：库变量全部用 `!default`，使用者提前定义同名变量即可覆盖默认值
2. **配合模块系统的 `with` 配置**（见 [08-模块化(@use与@forward)](./08-模块化%28@use与@forward%29.md)）

```scss
// _library.scss —— 库的默认配置
$black: #000 !default;
$border-radius: 0.25rem !default;

code {
  border-radius: $border-radius;
}
```

```scss
// 使用者覆盖默认值（模块系统下用 with 配置更规范，见 08 篇）
@use 'library' with (
  $border-radius: 0.1rem
);
```

### 五、Sass 变量 vs CSS 自定义属性（重点对比）

这是最容易混淆的一组概念，务必分清：

| 对比项 | SCSS 变量（`$var`） | CSS 自定义属性（`--var`） |
| --- | --- | --- |
| 生效时机 | **编译时**求值，编译后消失 | **运行时**（浏览器里）生效 |
| 能否动态修改 | 不能，编译完就固定了 | 能，JS 可改，媒体查询可改 |
| 作用域 | Sass 语法作用域 | DOM 层级继承 |
| 同一时间取值 | 全局唯一值 | 不同元素可以有不同的值 |
| 声明位置 | 任何地方 | 只能在选择器规则内（通常 `:root`） |
| 值类型 | 7 种 Sass 类型 | 几乎任意 CSS 值 |

```scss
// SCSS 变量：改一次值，之前用它的地方不变（命令式）
$variable: value1;
.rule-1 { value: $variable; } // value1
$variable: value2;
.rule-2 { value: $variable; } // value2

// CSS 变量：改一次值，所有引用处都变（声明式）
:root {
  --main-color: #409eff;
}
.button { color: var(--main-color); }  // 运行时取值
.alert  { color: var(--main-color); }  // 运行时取值
```

> 💡 **提示：** 需要运行时换肤、JS 操作样式 → 用 CSS 自定义属性；只是编译期复用值 → 用 SCSS 变量。两者经常配合：`--primary: #{$primary};`

在 SCSS 中声明 CSS 自定义属性时，**值默认按纯文本处理**，Sass 变量必须用插值注入：

```scss
$primary: #81899b;

:root {
  --primary: #{$primary};  // ✅ 插值注入 Sass 变量
  --wrong: $primary;       // ❌ 原样输出字符串 "$primary"，不会求值
}
```

### 六、数据类型详解

#### 1. 数字与单位

数字由"数值 + 单位"组成（`16px` = 16 + px），也可以没有单位：

```scss
@debug 100;    // 100
@debug 16px;   // 16px
@debug 5px * 2; // 10px
```

- 相同量纲的单位会自动换算：`1in + 6px` 得 `102px`（CSS 规定 1in = 96px）
- 不兼容的单位相加直接报错：`1in + 1s` ❌
- `50%` 和 `0.5` 是**不同的值**——百分比在 Sass 中是一种单位，两者不通用

> ⚠️ **注意：** 不要用 `#{$number}px` 给无单位数字拼单位——插值结果是**字符串**，不能参与后续数学运算。应该写 `$number * 1px`，或者一开始就让变量带上单位。

#### 2. 字符串

```scss
$name: "Helvetica"; // 带引号字符串
$font: sans-serif;  // 不带引号字符串
```

插值 `#{}` 可以把带引号字符串的引号去掉（输出无引号形式）。

#### 3. 布尔值与真值判断

Sass 只有 `false` 和 `null` 是**假值（falsey）**，其余一切（包括 `0`、空字符串、空列表）都是**真值（truthy）**：

```scss
// 0 也是 truthy，这点和 JavaScript 不同！
@if 0 { /* 会执行 */ }
@if null { /* 不会执行 */ }
@if "" { /* 会执行（空字符串是 truthy） */ }
```

#### 4. null

`null` 表示"没有值"：

- 属性值为 `null` 时，**该属性不会输出到 CSS**（可用来按条件"删掉"属性）
- 变量值为 `null` 时，`!default` 可以覆盖它

```scss
$border-color: null;

.card {
  border-color: $border-color; // 属性值是 null → 整条声明不输出 ✅
}

// 配合条件按需输出属性（if() 是内置条件函数：真取第二个值，假取第三个）
$rounded-corners: false;

.button {
  border: 1px solid black;
  border-radius: if($rounded-corners, 5px, null); // false → null → 该属性不输出
}
```

> ⚠️ **注意：** 只有属性值**整体**为 `null` 才会被省略；`null` 参与其他运算（如 `1px solid $null-var`）会报错。

### 七、实际应用场景

```scss
// 场景：设计规范 token 化
$spacing-unit: 8px;
$spacing-xs: $spacing-unit * 1;  // 8px
$spacing-sm: $spacing-unit * 2;  // 16px
$spacing-lg: $spacing-unit * 4;  // 32px

.card {
  padding: $spacing-sm $spacing-lg;
  gap: $spacing-xs;
}
```

```scss
// 场景：map + 循环批量生成工具类（变量 + map + @each 组合拳）
$font-weights: ("regular": 400, "medium": 500, "bold": 700);

@each $name, $weight in $font-weights {
  .font-#{$name} {
    font-weight: $weight;
  }
}
```

### 八、常见问题与注意事项

1. **变量必须先声明后使用**（顺序执行），用在声明之前会报错。
2. **不能用插值动态创建变量名**（`$theme-color-#{$name}` ❌）。官方建议用 map 代替：`map.get($theme-colors, $name)`。
3. **`meta.variable-exists()` / `meta.global-variable-exists()`** 可以检查变量是否存在（需要 `@use "sass:meta"`）。
4. **内置模块的变量不可修改**：`math.$pi: 0;` 会直接报错。
5. SCSS 变量名区分大小写：`$color` 和 `$Color` 是两个变量。

### 九、总结

- `$` 开头声明，顶层是全局、块内是局部，局部同名会**遮蔽**而不是覆盖
- `!default` = "没有才用"，是主题库标配；`!global` = "赋值给全局"，且只能赋值给已存在的变量
- Sass 变量是**编译期**的、命令式的；CSS 自定义属性是**运行时**的、声明式的
- 记住真假值规则：只有 `false` 和 `null` 是假，`0` 和空串都是真

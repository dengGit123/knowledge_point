# JavaScript 字符串方法详解

## 概述

JavaScript 字符串是不可变的字符序列，提供了丰富的内置方法用于操作字符串。所有字符串方法都不会修改原字符串，而是返回新字符串。

---

## 一、查找方法

### 1. `indexOf(searchValue, fromIndex)`

**作用**：从字符串开头查找指定值，返回第一次出现的索引，未找到返回 `-1`

**参数**：
- `searchValue`：要查找的字符串
- `fromIndex`（可选）：开始查找的位置，默认为 `0`

```javascript
const str = 'Hello World';
str.indexOf('o');      // 4
str.indexOf('o', 5);   // 7
str.indexOf('abc');    // -1
```

**注意**：区分大小写；`fromIndex` 为负数时视为 `0`

---

### 2. `lastIndexOf(searchValue, fromIndex)`

**作用**：从字符串末尾查找指定值，返回最后一次出现的索引，未找到返回 `-1`

**参数**：
- `searchValue`：要查找的字符串
- `fromIndex`（可选）：从该位置开始向前查找，默认为 `string.length - 1`

```javascript
const str = 'Hello World';
str.lastIndexOf('o');      // 7
str.lastIndexOf('o', 5);   // 4
```

**注意**：查找方向是从后向前，但返回的索引仍是从左开始计算

---

### 3. `includes(searchValue, fromIndex)`

**作用**：判断字符串是否包含指定值，返回 `true` 或 `false`

**参数**：
- `searchValue`：要查找的字符串
- `fromIndex`（可选）：开始查找的位置，默认为 `0`

```javascript
const str = 'Hello World';
str.includes('World');     // true
str.includes('world');     // false（区分大小写）
str.includes('o', 5);      // true
```

**注意**：区分大小写；ES6 新增方法

---

### 4. `startsWith(searchValue, fromIndex)`

**作用**：判断字符串是否以指定值开头，返回 `true` 或 `false`

**参数**：
- `searchValue`：要查找的字符串
- `fromIndex`（可选）：从该位置开始判断，默认为 `0`

```javascript
const str = 'Hello World';
str.startsWith('Hello');   // true
str.startsWith('World');   // false
str.startsWith('World', 6);// true（从索引6开始）
```

**注意**：区分大小写；ES6 新增方法

---

### 5. `endsWith(searchValue, length)`

**作用**：判断字符串是否以指定值结尾，返回 `true` 或 `false`

**参数**：
- `searchValue`：要查找的字符串
- `length`（可选）：视为字符串的长度，默认为 `string.length`

```javascript
const str = 'Hello World';
str.endsWith('World');     // true
str.endsWith('Hello');     // false
str.endsWith('Hello', 5);  // true（只看前5个字符）
```

**注意**：区分大小写；ES6 新增方法

---

## 二、获取字符方法

### 1. `charAt(index)`

**作用**：返回指定索引位置的字符

**参数**：
- `index`：字符的索引位置

```javascript
const str = 'Hello';
str.charAt(0);   // 'H'
str.charAt(4);   // 'o'
str.charAt(10);  // ''（超出范围返回空字符串）
str.charAt(-1);  // ''（负数返回空字符串）
```

**注意**：索引从 `0` 开始；超出范围返回空字符串

---

### 2. `charCodeAt(index)`

**作用**：返回指定索引位置字符的 UTF-16 编码（0-65535）

**参数**：
- `index`：字符的索引位置

```javascript
const str = 'Hello';
str.charCodeAt(0);   // 72（'H' 的ASCII码）
str.charCodeAt(4);   // 111（'o' 的ASCII码）
str.charCodeAt(10);  // NaN（超出范围）
```

**注意**：超出范围返回 `NaN`；只能处理 UTF-16 编码（0xFFFF 以内）

---

### 3. `codePointAt(index)`

**作用**：返回指定索引位置字符的 Unicode 码点

**参数**：
- `index`：字符的索引位置

```javascript
const str = '𝌆Hello';  // 𝌆 是一个 Unicode 表情符号
str.codePointAt(0);   // 0x1D306（十进制 119558）
str.charCodeAt(0);    // 0xD834（只能获取代理对的第一个）
```

**注意**：ES6 新增方法；能正确处理 Unicode 代理对（超出 0xFFFF 的字符）

---

## 三、截取方法

### 1. `slice(startIndex, endIndex)`

**作用**：截取字符串的一部分，返回新字符串

**参数**：
- `startIndex`：开始索引（包含）
- `endIndex`（可选）：结束索引（不包含），默认截取到末尾

```javascript
const str = 'Hello World';
str.slice(0, 5);    // 'Hello'
str.slice(6);       // 'World'
str.slice(-5);      // 'World'（负数从末尾开始计算）
str.slice(6, 11);   // 'World'
str.slice(11, 6);   // ''（start > end 返回空字符串）
```

**注意**：
- 支持负数索引（从末尾开始）
- `startIndex >= endIndex` 返回空字符串
- 超出范围自动修正到边界

---

### 2. `substring(startIndex, endIndex)`

**作用**：截取字符串的一部分，返回新字符串

**参数**：
- `startIndex`：开始索引（包含）
- `endIndex`（可选）：结束索引（不包含），默认截取到末尾

```javascript
const str = 'Hello World';
str.substring(0, 5);    // 'Hello'
str.substring(6);       // 'World'
str.substring(11, 6);   // 'World'（自动交换顺序）
str.substring(-5);      // 'Hello World'（负数视为 0）
```

**注意**：
- **不支持负数索引**（负数视为 `0`）
- `startIndex > endIndex` 时自动交换
- 更适合处理不确定顺序的索引

---

### 3. `substr(startIndex, length)`

**作用**：从指定位置开始截取指定长度的字符串

**参数**：
- `startIndex`：开始索引（包含）
- `length`（可选）：截取的长度，默认截取到末尾

```javascript
const str = 'Hello World';
str.substr(0, 5);    // 'Hello'
str.substr(6);       // 'World'
str.substr(-5);      // 'World'（负数从末尾开始）
str.substr(0, 0);    // ''（长度为0返回空字符串）
```

**注意**：
- 支持负数索引
- **已废弃**，建议使用 `slice` 或 `substring`
- `length` 为负数时返回空字符串

---

## 四、替换方法

### 1. `replace(searchValue, replacement)`

**作用**：替换字符串中的指定内容，返回新字符串

**参数**：
- `searchValue`：字符串或正则表达式
- `replacement`：替换的字符串或回调函数

```javascript
const str = 'Hello World';
str.replace('o', '*');         // 'Hell* World'（只替换第一个）
str.replace(/o/g, '*');        // 'Hell* W*rld'（替换所有）
str.replace(/o/gi, '*');       // 'Hell* W*rld'（不区分大小写）

// 使用回调函数
str.replace(/\w+/g, match => match.toUpperCase());  // 'HELLO WORLD'
```

**注意**：
- 默认只替换第一个匹配项
- 需要全局替换时使用正则表达式并加上 `g` 标志
- `replacement` 可以使用特殊字符：`$&`（匹配的文本）、`$1`（捕获组）等

---

### 2. `replaceAll(searchValue, replacement)`

**作用**：替换字符串中所有匹配的内容，返回新字符串

**参数**：
- `searchValue`：字符串或正则表达式
- `replacement`：替换的字符串或回调函数

```javascript
const str = 'Hello World';
str.replaceAll('o', '*');      // 'Hell* W*rld'（替换所有）
str.replaceAll(/o/g, '*');     // 'Hell* W*rld'（正则必须带g标志）
```

**注意**：
- ES2021 新增方法
- 如果 `searchValue` 是正则表达式，必须加上 `g` 标志，否则报错
- 比 `replace(/.../g)` 更直观

---

## 五、分割方法

### 1. `split(separator, limit)`

**作用**：将字符串分割成数组，返回新数组

**参数**：
- `separator`：分隔符（字符串或正则表达式）
- `limit`（可选）：限制返回数组的最大长度

```javascript
const str = 'apple,banana,orange';
str.split(',');           // ['apple', 'banana', 'orange']
str.split(',', 2);        // ['apple', 'banana']（限制长度）
str.split('');            // ['a','p','p','l','e',',','b',...]（每个字符分割）
str.split(/,|\s/);        // 使用正则分割
```

**注意**：
- 空字符串 `''` 会将字符串分割成单个字符数组
- `separator` 为 `undefined` 时返回包含原字符串的数组
- 相邻分隔符会产生空字符串元素

---

## 六、大小写转换方法

### 1. `toUpperCase()`

**作用**：将字符串转换为大写

```javascript
const str = 'Hello World';
str.toUpperCase();   // 'HELLO WORLD'
```

**注意**：不修改原字符串

---

### 2. `toLowerCase()`

**作用**：将字符串转换为小写

```javascript
const str = 'Hello World';
str.toLowerCase();   // 'hello world'
```

**注意**：不修改原字符串

---

### 3. `toLocaleUpperCase(locale)`

**作用**：根据特定语言环境将字符串转换为大写

**参数**：
- `locale`（可选）：语言环境，如 `'zh-CN'`、`'en-US'`

```javascript
const str = 'istanbul';
str.toUpperCase();           // 'ISTANBUL'
str.toLocaleUpperCase('tr'); // 'İSTANBUL'（土耳其语特殊处理）
```

---

### 4. `toLocaleLowerCase(locale)`

**作用**：根据特定语言环境将字符串转换为小写

**参数**：
- `locale`（可选）：语言环境

---

## 七、去空白方法

### 1. `trim()`

**作用**：去除字符串两端的空白字符

```javascript
const str = '  Hello World  ';
str.trim();   // 'Hello World'
```

**注意**：不影响字符串中间的空白；ES5 方法

---

### 2. `trimStart()` / `trimLeft()`

**作用**：去除字符串开头的空白字符

```javascript
const str = '  Hello World  ';
str.trimStart();   // 'Hello World  '
str.trimLeft();    // 同上（别名）
```

**注意**：ES2019 新增方法

---

### 3. `trimEnd()` / `trimRight()`

**作用**：去除字符串末尾的空白字符

```javascript
const str = '  Hello World  ';
str.trimEnd();     // '  Hello World'
str.trimRight();   // 同上（别名）
```

**注意**：ES2019 新增方法

---

## 八、填充方法

### 1. `padStart(length, padString)`

**作用**：在字符串开头填充指定字符，直到达到指定长度

**参数**：
- `length`：目标长度
- `padString`（可选）：填充的字符，默认为空格

```javascript
const str = '5';
str.padStart(2, '0');      // '05'
str.padStart(5, '0');      // '00005'
str.padStart(1, '0');      // '5'（原长度已大于等于目标长度）
```

**注意**：ES2017 新增方法

---

### 2. `padEnd(length, padString)`

**作用**：在字符串末尾填充指定字符，直到达到指定长度

**参数**：
- `length`：目标长度
- `padString`（可选）：填充的字符，默认为空格

```javascript
const str = '5';
str.padEnd(2, '0');        // '50'
str.padEnd(5, 'x');        // '5xxxx'
```

**注意**：ES2017 新增方法

---

## 九、重复方法

### 1. `repeat(count)`

**作用**：将字符串重复指定次数，返回新字符串

**参数**：
- `count`：重复次数（非负整数）

```javascript
const str = 'abc';
str.repeat(3);     // 'abcabcabc'
str.repeat(0);     // ''
str.repeat(1);     // 'abc'
```

**注意**：
- ES6 新增方法
- `count` 必须是非负整数，否则报错
- `count` 为 `0` 返回空字符串

---

## 十、连接方法

### 1. `concat(str1, str2, ...)`

**作用**：连接两个或多个字符串，返回新字符串

**参数**：
- `str1, str2, ...`：要连接的字符串

```javascript
const str1 = 'Hello';
const str2 = ' ';
const str3 = 'World';
str1.concat(str2, str3);   // 'Hello World'
```

**注意**：通常更推荐使用 `+` 运算符或模板字符串

---

## 十一、正则相关方法

### 1. `match(regexp)`

**作用**：查找字符串中匹配正则表达式的内容，返回匹配数组或 `null`

**参数**：
- `regexp`：正则表达式

```javascript
const str = 'Hello World 123';
str.match(/\d+/);          // ['123']（无g标志，返回第一个匹配及捕获组）
str.match(/\d+/g);         // ['123']（有g标志，返回所有匹配）
str.match(/\w+/g);         // ['Hello', 'World', '123']
str.match(/abc/);          // null（无匹配）
```

**注意**：
- 无 `g` 标志时返回详细匹配信息（含索引、输入等）
- 有 `g` 标志时只返回匹配的字符串数组

---

### 2. `matchAll(regexp)`

**作用**：返回一个包含所有匹配结果的迭代器

**参数**：
- `regexp`：正则表达式（必须带 `g` 标志）

```javascript
const str = 'Hello World 123';
const matches = str.matchAll(/\w+/g);
for (const match of matches) {
  console.log(match);  // 每个匹配的详细信息
}
```

**注意**：ES2020 新增方法；返回迭代器，需要转换为数组或使用 for...of 遍历

---

### 3. `search(regexp)`

**作用**：查找第一个匹配正则表达式的位置，返回索引或 `-1`

**参数**：
- `regexp`：正则表达式

```javascript
const str = 'Hello World';
str.search(/o/);       // 4
str.search(/o/g);      // 4（忽略g标志，只返回第一个）
str.search(/abc/);     // -1
```

**注意**：
- 只返回第一个匹配的索引
- 忽略正则表达式的 `g` 标志

---

## 十二、其他方法

### 1. `localeCompare(compareString, locales, options)`

**作用**：比较两个字符串，返回数字表示比较结果

**参数**：
- `compareString`：要比较的字符串
- `locales`（可选）：语言环境
- `options`（可选）：比较选项

```javascript
const str1 = 'apple';
const str2 = 'banana';
str1.localeCompare(str2);   // -1（str1 < str2）
str2.localeCompare(str1);   // 1（str2 > str1）
str1.localeCompare('apple');// 0（相等）
```

**注意**：
- 返回值：`-1`（小于）、`0`（等于）、`1`（大于）
- 适合进行自然语言排序

---

### 2. `normalize(form)`

**作用**：将字符串标准化为指定的 Unicode 形式

**参数**：
- `form`（可选）：标准化形式，可选值为 `'NFC'`、`'NFD'`、`'NFKC'`、`'NFKD'`

```javascript
const str = '\u00e9';    // 'é'
const str2 = '\u0065\u0301';  // 同样是 'é'，但由两个字符组成
str.normalize() === str2.normalize();  // true
```

**注意**：用于处理 Unicode 等价性问题

---

## 十三、注意事项

### 1. 字符串不可变性

所有字符串方法都**不会修改原字符串**，而是返回新字符串：

```javascript
const str = 'Hello';
str.toUpperCase();   // 返回 'HELLO'
console.log(str);    // 仍然是 'Hello'
```

### 2. 索引从 0 开始

字符串索引从 `0` 开始，最后一个字符的索引是 `length - 1`

### 3. 区分大小写

大多数字符串方法（`indexOf`、`includes`、`replace` 等）都**区分大小写**

### 4. 空字符串处理

- `indexOf('')` 返回 `0`
- `split('')` 返回每个字符组成的数组
- `substring(0, 0)` 返回空字符串

### 5. 边界情况

- 索引超出范围时，`charAt` 返回空字符串，`charCodeAt` 返回 `NaN`
- `slice` 和 `substring` 在边界情况表现不同（见上文）

### 6. 性能考虑

- 频繁拼接字符串使用 `+=` 可能性能较差，推荐使用数组 `push` + `join`
- 长字符串操作时注意方法的时间复杂度

### 7. 兼容性

- ES6+ 方法（`includes`、`startsWith`、`endsWith`、`repeat`、`padStart`、`padEnd`）在旧浏览器中需要 polyfill
- `replaceAll`、`matchAll` 等 ES2020+ 方法兼容性更差

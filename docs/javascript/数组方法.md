# JavaScript 数组方法详解

## 概述

JavaScript 数组是有序的数据集合，提供了丰富的内置方法用于操作数组。数组方法分为两类：

- **变异方法（Mutating）**：直接修改原数组
- **非变异方法（Non-mutating）**：不修改原数组，返回新数组或值

---

## 一、变异方法（修改原数组）

### 1. `push(element1, element2, ...)`

**作用**：向数组末尾添加一个或多个元素，返回新数组长度

**参数**：
- `element1, element2, ...`：要添加的元素

```javascript
const arr = [1, 2, 3];
const length = arr.push(4, 5);  // 返回 5
console.log(arr);  // [1, 2, 3, 4, 5]
```

**注意**：返回值是新长度，不是新数组

---

### 2. `pop()`

**作用**：移除数组最后一个元素，返回被移除的元素

**参数**：无

```javascript
const arr = [1, 2, 3];
const last = arr.pop();  // 返回 3
console.log(arr);  // [1, 2]
```

**注意**：空数组调用 `pop()` 返回 `undefined`

---

### 3. `unshift(element1, element2, ...)`

**作用**：向数组开头添加一个或多个元素，返回新数组长度

**参数**：
- `element1, element2, ...`：要添加的元素

```javascript
const arr = [3, 4, 5];
const length = arr.unshift(1, 2);  // 返回 5
console.log(arr);  // [1, 2, 3, 4, 5]
```

**注意**：性能较差，因为需要移动所有元素

---

### 4. `shift()`

**作用**：移除数组第一个元素，返回被移除的元素

**参数**：无

```javascript
const arr = [1, 2, 3];
const first = arr.shift();  // 返回 1
console.log(arr);  // [2, 3]
```

**注意**：性能较差，因为需要移动所有元素

---

### 5. `splice(startIndex, deleteCount, element1, ...)`

**作用**：从指定位置删除/插入元素，返回被删除的元素数组

**参数**：
- `startIndex`：开始位置（支持负数）
- `deleteCount`：删除的元素数量（0表示不删除）
- `element1, ...`（可选）：要插入的元素

```javascript
const arr = [1, 2, 3, 4, 5];

// 删除元素
const removed = arr.splice(2, 2);  // 返回 [3, 4]
console.log(arr);  // [1, 2, 5]

// 插入元素
arr.splice(2, 0, 3, 4);  // 返回 []
console.log(arr);  // [1, 2, 3, 4, 5]

// 替换元素
arr.splice(2, 2, 'a', 'b');  // 返回 [3, 4]
console.log(arr);  // [1, 2, 'a', 'b', 5]
```

**注意**：
- `startIndex` 超出范围时，从数组末尾开始
- `deleteCount` 省略时，删除到数组末尾

---

### 6. `reverse()`

**作用**：反转数组元素的顺序，返回原数组（已反转）

**参数**：无

```javascript
const arr = [1, 2, 3];
const reversed = arr.reverse();  // 返回 [3, 2, 1]
console.log(arr);  // [3, 2, 1]
console.log(arr === reversed);  // true（同一引用）
```

**注意**：直接修改原数组

---

### 7. `sort(compareFunction)`

**作用**：对数组元素进行排序，返回原数组（已排序）

**参数**：
- `compareFunction`（可选）：比较函数，决定排序顺序

```javascript
const arr = [3, 1, 4, 2];

// 默认排序（按Unicode码点）
arr.sort();  // [1, 2, 3, 4]

// 自定义排序（数字升序）
arr.sort((a, b) => a - b);  // [1, 2, 3, 4]

// 自定义排序（数字降序）
arr.sort((a, b) => b - a);  // [4, 3, 2, 1]

// 对象数组排序
const users = [
  { name: 'Bob', age: 30 },
  { name: 'Alice', age: 25 }
];
users.sort((a, b) => a.age - b.age);  // 按年龄升序
```

**注意**：
- 默认按字符串比较，数字需自定义比较函数
- 直接修改原数组

---

### 8. `fill(value, startIndex, endIndex)`

**作用**：用指定值填充数组的一部分，返回原数组

**参数**：
- `value`：填充的值
- `startIndex`（可选）：开始位置，默认为 `0`
- `endIndex`（可选）：结束位置（不包含），默认为 `length`

```javascript
const arr = [1, 2, 3, 4, 5];

arr.fill(0);  // [0, 0, 0, 0, 0]
arr.fill(9, 2);  // [0, 0, 9, 9, 9]
arr.fill(5, 1, 3);  // [0, 5, 5, 9, 9]
```

**注意**：直接修改原数组；支持负数索引

---

### 9. `copyWithin(targetIndex, startIndex, endIndex)`

**作用**：复制数组的一部分到同一数组的另一位置，返回原数组

**参数**：
- `targetIndex`：目标位置（开始粘贴的位置）
- `startIndex`（可选）：开始复制的位置，默认为 `0`
- `endIndex`（可选）：结束复制的位置（不包含），默认为 `length`

```javascript
const arr = [1, 2, 3, 4, 5];

arr.copyWithin(0, 3);  // [4, 5, 3, 4, 5]（复制索引3开始的元素到索引0）
arr.copyWithin(1, 0, 2);  // [4, 4, 5, 4, 5]
```

**注意**：直接修改原数组；不改变数组长度

---

## 二、非变异方法（不修改原数组）

### 1. `concat(arr1, arr2, ...)`

**作用**：连接两个或多个数组，返回新数组

**参数**：
- `arr1, arr2, ...`：要连接的数组或值

```javascript
const arr1 = [1, 2];
const arr2 = [3, 4];
const arr3 = [5, 6];

const result = arr1.concat(arr2, arr3);  // [1, 2, 3, 4, 5, 6]
const result2 = arr1.concat(3, [4, 5]);  // [1, 2, 3, 4, 5]
```

**注意**：
- 原数组不变
- 浅拷贝，对象引用保持不变

---

### 2. `slice(startIndex, endIndex)`

**作用**：截取数组的一部分，返回新数组

**参数**：
- `startIndex`：开始索引（包含），支持负数
- `endIndex`（可选）：结束索引（不包含），默认到末尾

```javascript
const arr = [1, 2, 3, 4, 5];

arr.slice(1, 4);    // [2, 3, 4]
arr.slice(2);       // [3, 4, 5]
arr.slice(-3);      // [3, 4, 5]
arr.slice();        // [1, 2, 3, 4, 5]（浅拷贝）
```

**注意**：
- 原数组不变
- 浅拷贝
- `startIndex >= endIndex` 返回空数组

---

### 3. `join(separator)`

**作用**：将数组元素连接成字符串，返回新字符串

**参数**：
- `separator`（可选）：分隔符，默认为 `','`

```javascript
const arr = ['Hello', 'World'];

arr.join();        // 'Hello,World'
arr.join(' ');     // 'Hello World'
arr.join('-');     // 'Hello-World'
arr.join('');      // 'HelloWorld'
```

**注意**：原数组不变

---

### 4. `toString()`

**作用**：将数组转换为字符串，返回新字符串

**参数**：无

```javascript
const arr = [1, 2, 3];
arr.toString();  // '1,2,3'
```

**注意**：相当于 `join(',')`

---

### 5. `toLocaleString(locales, options)`

**作用**：将数组转换为本地化字符串

**参数**：
- `locales`（可选）：语言环境
- `options`（可选）：格式化选项

```javascript
const arr = [123456.789, new Date()];
arr.toLocaleString('zh-CN');  // '123,456.789,2024/1/1 12:00:00'
```

---

## 三、迭代方法（高阶函数）

**遍历控制能力对比**：

| 方法 | 能否跳过元素 | 能否提前终止 | 终止条件 |
|------|-------------|-------------|----------|
| `forEach` | ✅ (`return`) | ❌ | - |
| `map` | ✅ (`return` 返回 undefined) | ❌ | - |
| `filter` | ✅ (`return false`) | ❌ | - |
| `reduce` | ✅ (返回原累积值) | ❌ | - |
| `find` | ❌ | ✅ | 回调返回 `true` |
| `findIndex` | ❌ | ✅ | 回调返回 `true` |
| `every` | ❌ | ✅ | 回调返回 `false` |
| `some` | ❌ | ✅ | 回调返回 `true` |

### 1. `forEach(callback, thisArg)`

**作用**：遍历数组，对每个元素执行回调函数

**参数**：
- `callback(currentValue, index, array)`：回调函数
  - `currentValue`：当前元素
  - `index`：当前索引
  - `array`：原数组
- `thisArg`（可选）：回调函数的 `this` 值

```javascript
const arr = [1, 2, 3];

arr.forEach((value, index) => {
  console.log(`索引${index}的值是${value}`);
});
// 索引0的值是1
// 索引1的值是2
// 索引2的值是3
```

**注意**：
- 无法中断遍历（不能用 `break`）
- 返回值为 `undefined`
- 不修改原数组（除非在回调中手动修改）

**控制遍历行为**：

```javascript
const arr = [1, 2, 3, 4, 5];

// 跳过当前元素（使用 return）
arr.forEach((value) => {
  if (value % 2 === 0) return;  // 跳过偶数
  console.log(value);  // 1, 3, 5
});

// 无法中断遍历（break 会报错）
arr.forEach((value) => {
  if (value === 3) break;  // ❌ 报错：Illegal break statement
});

// 强行中断（不推荐）
try {
  arr.forEach((value) => {
    if (value === 3) throw new Error('stop');
    console.log(value);  // 1, 2
  });
} catch (e) {
  if (e.message !== 'stop') throw e;
}
```

---

### 2. `map(callback, thisArg)`

**作用**：遍历数组，对每个元素执行回调并返回新数组

**参数**：
- `callback(currentValue, index, array)`：回调函数，返回新值
- `thisArg`（可选）：回调函数的 `this` 值

```javascript
const arr = [1, 2, 3];

const doubled = arr.map(value => value * 2);  // [2, 4, 6]
const squared = arr.map(value => value ** 2);  // [1, 4, 9]
const objects = arr.map((value, index) => ({ id: index, value }));
// [{ id: 0, value: 1 }, { id: 1, value: 2 }, { id: 2, value: 3 }]
```

**注意**：
- 返回新数组，长度与原数组相同
- 原数组不变

**控制遍历行为**：

```javascript
const arr = [1, 2, 3, 4, 5];

// 跳过当前元素（返回 undefined，会保留在结果中）
const result = arr.map((value) => {
  if (value % 2 === 0) return;  // 返回 undefined
  return value * 2;
});
// [2, undefined, 6, undefined, 10]

// 如果需要过滤掉某些元素，应该使用 filter + map
const filtered = arr
  .filter(value => value % 2 !== 0)  // 先过滤
  .map(value => value * 2);         // 再映射
// [2, 6, 10]

// 无法中断遍历
const result2 = arr.map((value) => {
  if (value === 3) break;  // ❌ 报错
  return value;
});
```

---

### 3. `filter(callback, thisArg)`

**作用**：过滤数组，返回满足条件的元素组成的新数组

**参数**：
- `callback(currentValue, index, array)`：回调函数，返回布尔值
- `thisArg`（可选）：回调函数的 `this` 值

```javascript
const arr = [1, 2, 3, 4, 5];

const even = arr.filter(value => value % 2 === 0);  // [2, 4]
const greaterThan3 = arr.filter(value => value > 3);  // [4, 5]
```

**注意**：
- 返回新数组，长度可能小于原数组
- 原数组不变

**控制遍历行为**：

```javascript
const arr = [1, 2, 3, 4, 5];

// filter 的"跳过"就是返回 false
const even = arr.filter((value) => {
  return value % 2 === 0;  // 返回 true 保留，false 跳过
});
// [2, 4]

// filter 的回调中无法提前终止遍历
const result = arr.filter((value) => {
  if (value === 3) break;  // ❌ 报错
  return value > 0;
});
```

---

### 4. `reduce(callback, initialValue)`

**作用**：将数组元素累积为单个值，返回最终累积结果

**参数**：
- `callback(accumulator, currentValue, index, array)`：回调函数
  - `accumulator`：累积器（上一次回调的返回值）
  - `currentValue`：当前元素
  - `index`：当前索引
  - `array`：原数组
- `initialValue`（可选）：累积器的初始值

```javascript
const arr = [1, 2, 3, 4, 5];

// 求和
const sum = arr.reduce((acc, val) => acc + val, 0);  // 15

// 求积
const product = arr.reduce((acc, val) => acc * val, 1);  // 120

// 数组扁平化
const nested = [[1, 2], [3, 4], [5]];
const flat = nested.reduce((acc, val) => acc.concat(val), []);  // [1, 2, 3, 4, 5]

// 统计频率
const words = ['apple', 'banana', 'apple', 'orange'];
const count = words.reduce((acc, val) => {
  acc[val] = (acc[val] || 0) + 1;
  return acc;
}, {});  // { apple: 2, banana: 1, orange: 1 }
```

**注意**：
- 无初始值时，第一个元素作为初始值，从第二个元素开始遍历
- 空数组无初始值会报错

**控制遍历行为**：

```javascript
const arr = [1, 2, 3, 4, 5];

// reduce 无法直接跳过元素，但可以选择不改变累积值
const sumOdd = arr.reduce((acc, value) => {
  if (value % 2 === 0) return acc;  // 跳过偶数，返回原累积值
  return acc + value;
}, 0);
// 9 (1 + 3 + 5)

// reduce 无法中断遍历
const result = arr.reduce((acc, value) => {
  if (value === 3) break;  // ❌ 报错
  return acc + value;
}, 0);

// 模拟中断：使用特殊标志
const sumUntil3 = arr.reduce((acc, value) => {
  if (acc.done) return acc;
  if (value === 3) {
    acc.done = true;
    return acc;
  }
  acc.sum += value;
  return acc;
}, { sum: 0, done: false });
// { sum: 3, done: true }
```

---

### 5. `reduceRight(callback, initialValue)`

**作用**：从右到左遍历数组，累积为单个值

**参数**：同 `reduce`

```javascript
const arr = [1, 2, 3];
const result = arr.reduceRight((acc, val) => acc - val, 0);
// 0 - 3 = -3, -3 - 2 = -5, -5 - 1 = -6
// 结果: -6
```

---

### 6. `find(callback, thisArg)`

**作用**：查找第一个满足条件的元素，返回该元素或 `undefined`

**参数**：
- `callback(currentValue, index, array)`：回调函数，返回布尔值
- `thisArg`（可选）：回调函数的 `this` 值

```javascript
const arr = [1, 2, 3, 4, 5];

const firstEven = arr.find(value => value % 2 === 0);  // 2
const greaterThan10 = arr.find(value => value > 10);  // undefined

const users = [
  { id: 1, name: 'Alice' },
  { id: 2, name: 'Bob' }
];
const user = users.find(u => u.id === 2);  // { id: 2, name: 'Bob' }
```

**注意**：
- 返回第一个匹配的元素
- 原数组不变

**控制遍历行为**：

```javascript
const arr = [1, 2, 3, 4, 5];

// find 可以提前终止：当回调返回 true 时立即停止，返回当前元素
arr.find((value) => {
  console.log(value);  // 1, 2（遇到2时返回true，停止遍历）
  return value % 2 === 0;
});
// 2

// 无法手动跳过元素（必须返回布尔值）
arr.find((value) => {
  if (value === 2) return;  // 返回 undefined，视为 false
  return value > 10;
});
// undefined
```

---

### 7. `findIndex(callback, thisArg)`

**作用**：查找第一个满足条件的元素索引，返回索引或 `-1`

**参数**：同 `find`

```javascript
const arr = [1, 2, 3, 4, 5];

arr.findIndex(value => value % 2 === 0);  // 1
arr.findIndex(value => value > 10);  // -1
```

**控制遍历行为**：

```javascript
const arr = [1, 2, 3, 4, 5];

// findIndex 可以提前终止：当回调返回 true 时立即停止，返回当前索引
arr.findIndex((value) => {
  console.log(value);  // 1, 2（遇到2时返回true，停止遍历）
  return value % 2 === 0;
});
// 1

// 无法手动跳过元素（必须返回布尔值）
arr.findIndex((value) => {
  if (value === 2) return;  // 返回 undefined，视为 false
  return value > 10;
});
// -1
```

---

### 8. `every(callback, thisArg)`

**作用**：判断所有元素是否都满足条件，返回 `true` 或 `false`

**参数**：
- `callback(currentValue, index, array)`：回调函数，返回布尔值
- `thisArg`（可选）：回调函数的 `this` 值

```javascript
const arr = [1, 2, 3, 4, 5];

arr.every(value => value > 0);  // true
arr.every(value => value > 3);  // false
```

**注意**：空数组调用返回 `true`（vacuous truth）

**控制遍历行为**：

```javascript
const arr = [1, 2, 3, 4, 5];

// every 可以提前终止：当回调返回 false 时立即停止
arr.every((value) => {
  console.log(value);  // 1, 2, 3（遇到3时返回false，停止遍历）
  return value < 3;
});
// false

// 无法手动跳过元素（必须返回布尔值）
arr.every((value) => {
  if (value === 2) return;  // 返回 undefined，视为 false
  return value > 0;
});
// false
```

---

### 9. `some(callback, thisArg)`

**作用**：判断是否有元素满足条件，返回 `true` 或 `false`

**参数**：同 `every`

```javascript
const arr = [1, 2, 3, 4, 5];

arr.some(value => value > 3);  // true
arr.some(value => value > 10);  // false
```

**注意**：空数组调用返回 `false`

**控制遍历行为**：

```javascript
const arr = [1, 2, 3, 4, 5];

// some 可以提前终止：当回调返回 true 时立即停止
arr.some((value) => {
  console.log(value);  // 1, 2（遇到2时返回true，停止遍历）
  return value % 2 === 0;
});
// true

// 无法手动跳过元素（必须返回布尔值）
arr.some((value) => {
  if (value === 2) return;  // 返回 undefined，视为 false
  return value > 10;
});
// false
```

---

### 10. `flat(depth)`

**作用**：扁平化嵌套数组，返回新数组

**参数**：
- `depth`（可选）：扁平化深度，默认为 `1`

```javascript
const arr = [1, [2, 3], [[4, 5], [6, 7]]];

arr.flat();      // [1, 2, 3, [4, 5], [6, 7]]（depth=1）
arr.flat(2);     // [1, 2, 3, 4, 5, 6, 7]（depth=2）
arr.flat(Infinity);  // 完全扁平化
```

**注意**：
- ES2019 新增方法
- 原数组不变

---

### 11. `flatMap(callback, thisArg)`

**作用**：先映射后扁平化（相当于 `map().flat(1)`），返回新数组

**参数**：
- `callback(currentValue, index, array)`：回调函数
- `thisArg`（可选）：回调函数的 `this` 值

```javascript
const arr = ['hello', 'world'];

arr.flatMap(str => str.split(''));  // ['h','e','l','l','o','w','o','r','l','d']

// 等价于
arr.map(str => str.split('')).flat(1);
```

**注意**：
- ES2019 新增方法
- 只扁平化一层

## 四、搜索方法

### 1. `indexOf(searchElement, fromIndex)`

**作用**：从开头查找元素，返回第一次出现的索引或 `-1`

**参数**：
- `searchElement`：要查找的元素
- `fromIndex`（可选）：开始查找的位置，默认为 `0`

```javascript
const arr = [1, 2, 3, 2, 1];

arr.indexOf(2);      // 1
arr.indexOf(2, 2);   // 3
arr.indexOf(4);      // -1
```

**注意**：使用严格相等（`===`）比较

---

### 2. `lastIndexOf(searchElement, fromIndex)`

**作用**：从末尾查找元素，返回最后一次出现的索引或 `-1`

**参数**：同 `indexOf`

```javascript
const arr = [1, 2, 3, 2, 1];

arr.lastIndexOf(2);     // 3
arr.lastIndexOf(2, 2);  // 1
```

---

### 3. `includes(searchElement, fromIndex)`

**作用**：判断数组是否包含指定元素，返回 `true` 或 `false`

**参数**：
- `searchElement`：要查找的元素
- `fromIndex`（可选）：开始查找的位置

```javascript
const arr = [1, 2, 3];

arr.includes(2);     // true
arr.includes(4);     // false
arr.includes(1, 1);  // false
```

**注意**：
- ES7 新增方法
- 使用严格相等（`===`）比较

---

## 五、静态方法

### 1. `Array.isArray(value)`

**作用**：判断值是否为数组，返回 `true` 或 `false`

**参数**：
- `value`：要判断的值

```javascript
Array.isArray([1, 2, 3]);  // true
Array.isArray('hello');    // false
Array.isArray({});         // false
Array.isArray(null);       // false
```

**注意**：比 `instanceof Array` 更可靠

---

### 2. `Array.from(arrayLike, mapFn, thisArg)`

**作用**：将类数组对象或可迭代对象转换为数组

**参数**：
- `arrayLike`：类数组对象或可迭代对象
- `mapFn`（可选）：映射函数
- `thisArg`（可选）：映射函数的 `this` 值

```javascript
// 类数组对象
const str = 'hello';
Array.from(str);  // ['h', 'e', 'l', 'l', 'o']

// Set
const set = new Set([1, 2, 3]);
Array.from(set);  // [1, 2, 3]

// 带映射函数
Array.from([1, 2, 3], x => x * 2);  // [2, 4, 6]
```

**注意**：ES6 新增方法

---

### 3. `Array.of(element1, element2, ...)`

**作用**：创建包含任意参数的数组

**参数**：
- `element1, element2, ...`：数组元素

```javascript
Array.of(1, 2, 3);  // [1, 2, 3]
Array.of(5);        // [5]（与 Array(5) 不同）
Array.of();         // []
```

**注意**：
- ES6 新增方法
- 区别于 `Array()`：`Array(5)` 创建长度为5的空数组，`Array.of(5)` 创建 `[5]`

## 六、其他方法

### 1. `length`

**作用**：获取或设置数组的长度

```javascript
const arr = [1, 2, 3];

arr.length;       // 3
arr.length = 2;   // 修改长度，截断数组
console.log(arr);  // [1, 2]
arr.length = 5;   // 扩展长度，填充 undefined
console.log(arr);  // [1, 2, undefined, undefined, undefined]
```

**注意**：设置长度小于当前长度会截断数组

---

### 2. `at(index)`

**作用**：获取指定索引的元素，支持负数索引

**参数**：
- `index`：索引位置（支持负数）

```javascript
const arr = [1, 2, 3, 4, 5];

arr.at(0);   // 1
arr.at(-1);  // 5（最后一个元素）
arr.at(-2);  // 4（倒数第二个元素）
```

**注意**：ES2022 新增方法

---

### 3. `entries()`

**作用**：返回包含键值对的迭代器

**参数**：无

```javascript
const arr = ['a', 'b', 'c'];
const iterator = arr.entries();

for (const [index, value] of iterator) {
  console.log(`${index}: ${value}`);
}
// 0: a
// 1: b
// 2: c
```

---

### 4. `keys()`

**作用**：返回包含索引的迭代器

**参数**：无

```javascript
const arr = ['a', 'b', 'c'];
for (const key of arr.keys()) {
  console.log(key);  // 0, 1, 2
}
```

---

### 5. `values()`

**作用**：返回包含元素值的迭代器

**参数**：无

```javascript
const arr = ['a', 'b', 'c'];
for (const value of arr.values()) {
  console.log(value);  // a, b, c
}
```

## 七、注意事项

### 1. 变异方法 vs 非变异方法

| 变异方法（修改原数组） | 非变异方法（返回新值） |
|------------------------|-----------------------|
| `push`, `pop` | `concat`, `slice` |
| `unshift`, `shift` | `join`, `toString` |
| `splice`, `reverse` | `map`, `filter` |
| `sort`, `fill` | `reduce`, `find` |
| `copyWithin` | `flat`, `flatMap` |

### 2. 迭代方法中的 `this`

迭代方法（`forEach`, `map`, `filter` 等）的第二个参数 `thisArg` 指定回调函数的 `this` 值。如果使用箭头函数，`thisArg` 会被忽略，因为箭头函数没有自己的 `this`。

### 3. 空数组的行为

```javascript
[].forEach(() => {});  // 不执行
[].map(() => {});      // 返回 []
[].filter(() => {});   // 返回 []
[].reduce(() => {});   // 报错（无初始值）
[].every(() => {});    // 返回 true
[].some(() => {});     // 返回 false
[].find(() => {});     // 返回 undefined
```

### 4. 稀疏数组

稀疏数组（有空槽的数组）在迭代时会跳过空槽：

```javascript
const arr = [1, , 3];  // 索引1是空槽

arr.forEach(val => console.log(val));  // 1, 3（跳过空槽）
arr.map(val => val * 2);               // [2, , 6]（保留空槽）
```

### 5. 性能考虑

- `push` 和 `pop` 性能优于 `unshift` 和 `shift`
- 频繁使用 `splice` 可能导致性能问题
- 大数组使用 `forEach` 比 `for` 循环略慢，但代码更清晰

### 6. 兼容性

| 方法 | ES版本 | 兼容性 |
|------|--------|--------|
| `forEach`, `map`, `filter`, `reduce`, `every`, `some` | ES5 | 良好 |
| `find`, `findIndex`, `includes`, `fill`, `copyWithin` | ES6 | IE不支持 |
| `flat`, `flatMap` | ES2019 | 需要polyfill |
| `at` | ES2022 | 需要polyfill |

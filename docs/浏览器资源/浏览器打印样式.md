# 浏览器打印样式

> 📖 官方文档：[MDN - CSS Paged Media（分页媒体）](https://developer.mozilla.org/zh-CN/docs/Web/CSS/CSS_paged_media) ｜ [MDN - @page](https://developer.mozilla.org/zh-CN/docs/Web/CSS/@page) ｜ [web.dev - CSS and print](https://web.dev/learn/css/print)

---

### 一、概述

**打印样式**指用户按下"打印"（或"另存为 PDF"）时，浏览器渲染纸张页面所用的样式。同一份 HTML，屏幕上是深色导航、悬浮按钮、无限滚动；到了纸上，这些都该变成干净的黑白排版——控制这个"变身"的技术就是打印样式控制。

为什么值得专门学？三个真实的痛点：

- 用户打印电商订单、报表、发票、简历时，页面上的**导航、广告、侧边栏全被带进纸张**，浪费纸且难看；
- **背景色和图片默认不打印**（省墨），设计稿里依赖背景色的色块全部消失；
- **分页随机断裂**：表格跨页断成两截、标题孤零零留在上一页末尾。

> 💡 **通俗理解**：屏幕渲染像"舞台演出"——灯光、背景、动效怎么炫怎么来；打印渲染像"演出场刊"——黑白、固定开本、按页装订。打印样式就是给"场刊"单独排版的一套规则。

### 二、原理：打印是另一种"媒体"

#### 1. 媒体（Media）的概念

CSS 本来就是分媒体的：`@media screen` 管屏幕、`@media print` 管打印、`@media speech` 管朗读。浏览器渲染打印内容时，会把**媒体类型切换为 `print`**，重新套用样式、按"页"（而不是连续滚动流）排版：

```
屏幕渲染（连续媒体）              打印渲染（分页媒体 Paged Media）
┌──────────────┐                ┌────────┬────────┬────────┐
│   视口        │                │ 第 1 页 │ 第 2 页 │ 第 3 页 │
│   ↓ 滚动      │     打印时     ├────────┴────────┴────────┤
│   内容无限延伸 │  ═════════→   │ 内容被"切割"成一页页固定   │
│              │                │ 尺寸的页面（如 A4）        │
└──────────────┘                └──────────────────────────┘
  布局单位：视口                   布局单位：页面盒（Page Box）
```

#### 2. 页面盒（Page Box）模型

打印时每个页面由"页面盒"描述：`@page` 规则控制它的尺寸与边距，页面内容在"页面区域"内排布：

```
┌─────────────────────────────┐ ← 页面盒（纸张）
│ ┌─────────────────────────┐ │
│ │  margin（页边距）        │ │ ← @page { margin: 2cm }
│ │  ┌───────────────────┐  │ │
│ │  │   页面区域          │  │ │ ← 真正排内容的地方
│ │  │  （Page Area）     │  │ │
│ │  └───────────────────┘  │ │
│ └─────────────────────────┘ │
└─────────────────────────────┘
```

> 💡 **关键认知：** `@page` 设置的边距是**纸张物理边距**，与页内元素的 `margin` 是两回事。用户在打印对话框里也可以设置"页边距"，最终效果受两者共同影响——要么全权交给 `@page`（提示用户选"默认边距"），要么不动 `@page`（由用户设置）。

#### 3. 两套控制入口的分工

| 手段 | 层级 | 管什么 |
|------|------|--------|
| `@media print` | **元素级** | 哪些元素显示/隐藏、字号颜色怎么变——"页面上放什么、长什么样" |
| `@page` | **页面级** | 纸张尺寸、页边距——"纸长什么样" |

### 三、控制手段一：@media print（元素级）

#### 1. 三种引入方式

```html
<!-- 方式①：<link> 带 media 属性 —— 打印时才应用这份 CSS -->
<link rel="stylesheet" href="print.css" media="print" />
```

```css
/* 方式②：写在同一份 CSS 里，用 @media 块包裹（最常用） */
@media print {
  .sidebar,
  .navbar,
  .ad-banner {
    display: none;      /* 打印时隐藏导航/侧栏/广告 */
  }

  body {
    color: #000;        /* 正文纯黑，避免浅灰打印不清 */
    background: #fff;
    font-size: 12pt;    /* 纸上单位用 pt/mm/cm，不用 px */
  }

  a {
    text-decoration: none;
    color: inherit;
  }
}
```

```css
/* 方式③：@import（不推荐，额外阻塞请求） */
@import url("print.css") print;
```

> 💡 **提示：** 方式①的 `<link media="print">` 浏览器会**以低优先级下载**、不阻塞首屏渲染——想单独维护打印样式表时优先用它。

#### 2. 打印适配的常见套路

```css
@media print {
  /* ① 隐藏交互元素：屏幕才有交互，纸上无意义 */
  button,
  .pagination,
  .video-player,
  .cookie-banner {
    display: none !important;
  }

  /* ② 展开折叠内容：屏幕上收起的正文，纸上应该展开 */
  .collapse-panel {
    display: block !important;
    height: auto !important;
    overflow: visible !important;
  }

  /* ③ 黑白化：把依赖颜色的信息改为形状/文字可辨 */
  .status-tag {
    background: none !important;
    border: 1px solid #000;          /* 用边框替代背景色块 */
  }

  /* ④ 打印链接的 URL：纸质文档看不到 href，补上 */
  a[href^="http"]::after {
    content: " (" attr(href) ")";
    font-size: 10pt;
    color: #555;
  }

  /* ⑤ 防止元素被截断 */
  .card,
  table,
  img {
    break-inside: avoid;             /* 见"分页控制"一节 */
  }
}
```

### 四、控制手段二：@page（页面级）

#### 1. 基本用法

```css
@page {
  size: A4 portrait;       /* 纸张：A4 竖向（landscape 为横向） */
  margin: 2cm;             /* 四边页边距 */
}
```

`size` 的取值：

| 写法 | 含义 |
|------|------|
| `auto` | 默认——跟随用户在打印对话框中选择的纸张 |
| `A4` / `A5` / `letter` | 命名纸张尺寸 |
| `portrait` / `landscape` | 只指定方向（尺寸跟随用户选择） |
| `A4 landscape` | 尺寸 + 方向组合 |
| `210mm 297mm` | 自定义宽 × 高 |

#### 2. 伪类选择器：首页、左右页单独设置

```css
@page :first {
  margin-top: 5cm;         /* 封面页：顶部留出标题区 */
}

@page :left {
  margin-right: 3cm;       /* 左页（偶数页）：装订侧在内侧右方 */
}

@page :right {
  margin-left: 3cm;        /* 右页（奇数页）：装订侧在内侧左方 */
}
```

#### 3. 命名页：不同章节用不同纸张方向

`page` 属性（CSS Named Pages）可以把元素绑定到命名的 `@page` 规则——超宽表格自动横排：

```css
/* 命名一个横向页面 */
@page wide {
  size: A4 landscape;
}

/* 含超宽表格的章节使用它 */
.chapter-data {
  page: wide;              /* 该区块的页面切换为横向 */
}

table.wide-table {
  width: 100%;
}
```

> ⚠️ **注意（兼容性）：** `@page { size }` 与命名页（`page` 属性）曾长期只有 Firefox/Safari 支持，**Chrome/Edge 到 131 版（2024 年 11 月）才补齐**——此前的 Chrome 会解析 `@page` 但忽略 `size`，纸张始终跟随打印对话框的选择。面向旧版 Chrome 用户时，要有"用户在对话框里自己选纸张/方向"的降级预期；`margin` 与 `:first`/`:left`/`:right` 伪类的支持则早得多、可放心使用。

### 五、控制手段三：分页控制（断页）

内容太长必然跨页，能控制的是"**在哪断、哪里不许断**"。现代规范用 `break-*` 系列（旧的 `page-break-*` 是它的别名）：

| 属性 | 作用 | 常用值 |
|------|------|--------|
| `break-before` | 在元素**前**分页 | `page`（强制分页）、`avoid`（避免） |
| `break-after` | 在元素**后**分页 | 同上 |
| `break-inside` | 禁止在元素**内部**断开 | `avoid`、`avoid-page` |

```css
@media print {
  /* 每个大章节从新的一页开始 */
  .chapter {
    break-before: page;
  }

  /* 这些块不允许被拦腰截断 */
  .card,
  figure,
  blockquote,
  tr {
    break-inside: avoid;
  }

  /* 标题不孤立：标题不允许留在上一页的末尾 */
  h2,
  h3 {
    break-after: avoid;
  }

  /* 表头跨页重复（打印表格的刚需） */
  thead {
    display: table-header-group;   /* 浏览器在每个续页顶部重复表头 */
  }
}
```

> ⚠️ **注意（易错点）：** `break-inside: avoid` 对**弹性布局（flex）和网格（grid）容器**经常失效——分页算法主要针对块级流。多列卡片列表要分页友好，建议打印时改回 `display: block` 或用 `columns` 多栏布局（分页算法对它支持更好）。另外，绝对定位（`position: absolute`）的元素会脱离分页流，打印前应改回静态定位。

新旧属性对照：

| 现代属性 | 旧别名（page-break-*） | 说明 |
|---------|----------------------|------|
| `break-before: page` | `page-break-before: always` | 旧属性源自 CSS2 时代，现为别名 |
| `break-inside: avoid` | `page-break-inside: avoid` | 写现代属性即可，无需重复写旧名 |

### 六、背景色与图片：省墨机制

打印时浏览器**默认不打印背景色和背景图**（`print-color-adjust` 默认值 `economy`，为省墨），这会让设计稿里的色块、标签底色全部消失：

```css
/* 请求浏览器精确打印颜色（跨浏览器写法） */
.status-badge {
  -webkit-print-color-adjust: exact;   /* Safari、旧 Chrome/Edge */
  print-color-adjust: exact;           /* 标准属性：Chrome 96+、Firefox 48+ */
}
```

| 值 | 行为 |
|----|------|
| `auto` | 由浏览器决定 |
| `economy`（默认） | 可能省略背景/图片以省墨 |
| `exact` | 请求按指定颜色精确渲染 |

> ⚠️ **注意（重要边界）：** `print-color-adjust: exact` 只是"请求"，**用户打印对话框里的"背景图形"（Background graphics）选项才是开关**——Safari 上即使声明了 `exact`，用户不勾选该选项背景依然不打印（Chrome/Firefox 目前会尊重 `exact`）。所以**不要让关键信息只靠背景色表达**：重要状态用边框、加粗、文字标注兜底。

`<img>` 图片的打印则相对可靠（默认打印），只需注意两点：给 `img` 设置 `max-width: 100%` 防溢出；纯装饰图（logo 除外）打印时可隐藏省墨。

### 七、实现步骤：一次完整的打印适配

把前面的手段按工程顺序串起来——给一个"订单详情页"做打印适配：

```text
第 1 步  审视页面：列出"纸上需要"与"纸上多余"的元素
         ├─ 需要：订单标题、商品表格、金额汇总、页脚信息
         └─ 多余：导航、侧边栏、按钮组、分页器、悬浮客服、广告
              │
第 2 步  写 @media print：隐藏多余 + 黑白化 + 展开折叠内容
              │
第 3 步  写 @page：纸张与边距（size: A4; margin: 15mm）
              │
第 4 步  分页控制：章节 break-before、卡片/表格行 break-inside: avoid、
         thead 重复、标题 break-after: avoid
              │
第 5 步  单位换算：屏幕 px/REM → 打印 pt/mm（正文字号 10.5pt~12pt）
              │
第 6 步  验证：Chrome DevTools → Rendering → Emulate CSS media type: print
         预览无误后 Cmd/Ctrl + P 用"另存为 PDF"实测分页
              │
第 7 步  （可选）JS 增强：打印按钮、动态内容打印、beforeprint 钩子
```

对应的核心样式（可直接作为模板）：

```css
@media print {
  /* 第 2 步：裁剪与黑白化 */
  .navbar,
  .sidebar,
  .actions,
  .floating-service {
    display: none !important;
  }

  body {
    color: #000;
    background: #fff;
    font-size: 12pt;
  }

  /* 第 4 步：分页控制 */
  .order-section {
    break-before: page;
  }

  table {
    break-inside: auto;              /* 长表格允许跨页 */
  }

  tr {
    break-inside: avoid;             /* 但单行不许截断 */
  }

  thead {
    display: table-header-group;     /* 续页重复表头 */
  }

  h2 {
    break-after: avoid;
  }

  img {
    max-width: 100%;
  }
}

/* 第 3 步：页面级（写在 @media 外，@page 本身只对打印生效） */
@page {
  size: A4;
  margin: 15mm;
}
```

> 💡 **提示：** 调试打印样式不必真的打印——Chrome DevTools 的 **Rendering 面板 → Emulate CSS media type → print** 可以在屏幕上实时预览打印排版，配合 `Cmd/Ctrl + P` 的预览窗口验证断页效果。

### 八、JS 控制打印

#### 1. `window.print()` 与 beforeprint / afterprint 事件

```html
<button id="print-btn">打印订单</button>
```

```ts
// 触发打印（打开系统打印对话框）
document.getElementById('print-btn')?.addEventListener('click', () => {
  window.print()
})

// 打印前：切换到"打印态"（如展开全部折叠面板）
window.addEventListener('beforeprint', () => {
  document.body.classList.add('printing')
})

// 打印后：恢复屏幕态
window.addEventListener('afterprint', () => {
  document.body.classList.remove('printing')
})
```

| 事件/方法 | 触发时机 | 兼容性 |
|-----------|---------|--------|
| `window.print()` | 调用即打开打印对话框（多数浏览器会阻塞后续 JS） | 全平台 |
| `beforeprint` | 打印对话框出现**前** | Chrome 63+、Firefox 6+、Safari 13+ |
| `afterprint` | 打印对话框关闭**后**（含取消） | 同上 |

> 💡 **提示：** `beforeprint/afterprint` 在用户通过**浏览器菜单**打印时同样触发（不只是 `window.print()`），适合做全局打印态管理。更早的 Safari 可用 `window.matchMedia('print')` 的 change 监听兜底。

#### 2. 只打印页面局部：隐藏 iframe 方案

打印的永远是"文档"，要打印局部内容，经典做法是把局部内容**写入隐藏 iframe**，打印这个 iframe（它有独立的文档和样式）：

```ts
/**
 * 打印任意 HTML 字符串（局部打印的通用方案）
 * 原理：iframe 拥有独立 document，打印时只作用于它
 */
function printHtml(html: string): void {
  // 1. 创建隐藏 iframe
  const iframe = document.createElement('iframe')
  iframe.style.position = 'fixed'
  iframe.style.right = '0'
  iframe.style.bottom = '0'
  iframe.style.width = '0'
  iframe.style.height = '0'
  iframe.style.border = '0'
  document.body.appendChild(iframe)

  const win = iframe.contentWindow
  if (!win) return

  // 2. 先注册监听（要在 doc.close() 触发 load 之前挂好）
  //    打印后立刻移除 iframe 可能取消打印任务（Chrome 已知行为），
  //    所以在 afterprint 里延时清理
  win.addEventListener('afterprint', () => {
    setTimeout(() => iframe.remove(), 500)
  })

  // 3. 写入内容与打印样式
  const doc = iframe.contentDocument
  if (!doc) return
  doc.open()
  doc.write(`
    <!DOCTYPE html>
    <html>
      <head>
        <style>
          @page { size: A4; margin: 15mm; }
          body { font-size: 12pt; color: #000; }
          table { width: 100%; border-collapse: collapse; }
          td, th { border: 1px solid #333; padding: 4pt 8pt; }
          tr { break-inside: avoid; }
        </style>
      </head>
      <body>${html}</body>
    </html>
  `)
  doc.close()

  // 4. 等 load（内容渲染完成）再打印：纯文本直接 print 通常没问题，
  //    含图片/字体时必须等资源就绪，否则纸上可能空白
  win.addEventListener('load', () => {
    win.focus()
    win.print()
  })
}

// 使用：只打印 #order 区域的 HTML
const orderHtml = document.getElementById('order')?.innerHTML ?? ''
printHtml(orderHtml)
```

> ⚠️ **注意（三个坑）：**
> 1. **写入后立刻 `print()` 可能丢内容**——图片、Web 字体未加载完。稳妥做法是等 iframe 的 `load` 事件或适度延时；
> 2. **打印后立刻移除 iframe 可能取消打印任务**（Chrome 已知行为）——监听 `afterprint` 清理，或 `setTimeout` 延时移除；
> 3. 复杂场景（批量打印、分页模板）可考虑成熟库（如 Print.js），它们封装了上述时序问题。

#### 3. Vue 3 组件封装（组合式 API）

```vue
<script setup lang="ts">
import { ref } from 'vue'

const props = defineProps<{
  /** 要打印的选择器，如 '#invoice' */
  target: string
}>()

const printing = ref(false)

function doPrint(): void {
  const el = document.querySelector(props.target)
  if (!el) return

  printing.value = true
  printHtml(el.innerHTML)      // 复用上面的 printHtml
  // 打印完成后恢复按钮状态（简化处理）
  setTimeout(() => {
    printing.value = false
  }, 1000)
}

defineExpose({ doPrint })
</script>

<template>
  <button :disabled="printing" @click="doPrint">
    {{ printing ? '准备打印…' : '打印' }}
  </button>
</template>
```

### 九、实际应用场景

#### 场景一：电商订单/发票打印

要点：隐藏一切交互元素；金额表格跨页安全；`thead` 重复。

```css
@media print {
  .nav, .goods-actions, .recommend { display: none !important; }
  table { width: 100%; border-collapse: collapse; }
  tr { break-inside: avoid; }
  thead { display: table-header-group; }
  .amount { text-align: right; font-weight: bold; }
}
```

#### 场景二：新闻/博客文章"阅读打印版"

要点：正文最大化可读性（衬线字体、11pt、1.6 行高）；链接补 URL；代码块防断页。

```css
@media print {
  article {
    font-family: Georgia, 'Songti SC', serif;
    font-size: 11pt;
    line-height: 1.6;
  }
  article a[href^='http']::after {
    content: ' (' attr(href) ')';
    font-size: 9pt;
    color: #555;
  }
  pre {
    break-inside: avoid;
    border: 1px solid #ccc;
    white-space: pre-wrap;
  }
}
```

#### 场景三：后台报表导出 PDF

要点：用户"打印 → 另存为 PDF"是最通用的前端导出方案；超宽表格用命名页横排；`@page` 控制边距统一版式。

```css
@page { size: A4; margin: 12mm; }
@page wide { size: A4 landscape; }

.report-table-section { page: wide; }   /* 超宽表横排 */
```

#### 场景四：简历/合同打印

要点：一页纸原则（每个区块 `break-inside: avoid`）；`@page :first` 控制首页边距；黑白化后确认关键信息仍可辨（底纹换边框）。

```css
@page :first { margin-top: 18mm; }

.resume-section {
  break-inside: avoid;          /* 每个段落块不跨页 */
}
h2 { break-after: avoid; }
```

### 十、常见问题与注意事项

#### 1. 陷阱速查表

| 陷阱 | 后果 | 正确做法 |
|------|------|---------|
| 打印样式用 `px` 定字号 | 各设备 DPI 不同，纸面大小不可控 | 用 `pt`（字号）、`mm`/`cm`（间距） |
| 依赖背景色传达信息 | 用户未勾"背景图形"时信息消失 | `print-color-adjust: exact` + 边框/文字兜底 |
| `position: fixed` 的元素 | 打印时通常在**每一页**重复或错位 | 打印时改为 `static`/`relative` |
| `break-inside: avoid` 加在 flex/grid 容器 | 经常不生效 | 打印时降级为块级布局或 `columns` |
| 长表格整体 `break-inside: avoid` | 超过一页的表格无法分页，内容被截断 | 表格允许 `auto`，只对 `tr` 避免 |
| `display: none` 的折叠面板 | 纸上内容缺失 | 打印态展开（`display: block !important`） |
| iframe 打印后立即 remove | 打印任务可能被取消 | `afterprint` 或延时清理 |
| 忘记 `max-width: 100%` | 图片溢出纸张边界 | `@media print { img { max-width: 100% } }` |

#### 2. 常见问题

**Q1：`@media print` 和 `@page` 可以互相嵌套吗？**

不能。`@page` 是顶层规则，不写在 `@media print` 里面；但 `@page` 本身只在打印时生效，直接写在样式表顶层即可。

**Q2：为什么预览时样式对了，真机打印背景还是没了？**

`print-color-adjust: exact` 只是网页侧的"请求"，打印对话框里的"背景图形"选项是用户侧的"开关"，Safari 尤其严格。设计上遵循"颜色只是装饰、信息靠文字与形状"即可彻底规避。

**Q3：`window.print()` 会阻塞页面吗？**

大多数浏览器会：对话框打开期间该页的 JS 暂停执行。所以不要指望"print 之后立即执行的代码"能及时运行——恢复逻辑放 `afterprint` 里。

**Q4：如何让某个元素"每页都出现"（如每页页脚）？**

CSS 分页媒体没有稳定的"每页重复元素"通用方案（`position: fixed` 的行为跨浏览器不一致且易与正文重叠）。规范提供的 `@page` 页边距盒（margin boxes，如 `@top-center`）目前**浏览器支持非常有限**，可靠做法是把内容拆分后用 JS 生成多页 DOM，或接受"仅首页/末页有页脚"的简化设计。

**Q5：打印和"另存为 PDF"有区别吗？**

对网页渲染而言流程一致（都是 print 媒体），但"另存为 PDF"不依赖打印机驱动，颜色、字体的还原度通常更稳定；给用户的导出功能建议引导走"另存为 PDF"。

### 十一、与相关概念对比

| 概念 | 与打印样式的关系 |
|------|-----------------|
| `@media screen` | 同属媒体查询；打印适配本质是"补上 print 分支" |
| `@media (prefers-color-scheme)` | 也是媒体特性，可与 `print` 组合（如打印时强制浅色） |
| 服务端 PDF 生成（Puppeteer 等） | 服务端渲染 PDF，样式控制力更强（页眉页脚、精确分页），前端打印样式是其轻量替代 |
| 打印库（Print.js 等） | 封装 iframe 时序与跨浏览器差异；理解原理后多数场景可手写 |

### 十二、总结

| 知识点 | 核心要点 |
|--------|---------|
| 原理 | 打印 = 媒体切换为 `print` + 连续媒体变分页媒体（Page Box） |
| 三大手段 | `@media print`（元素级）、`@page`（页面级）、`break-*`（分页点） |
| `@page` | `size`（Chrome 131+ 才支持）、`margin`（兼容性好）、`:first`/`:left`/`:right` 伪类 |
| 分页 | 章节 `break-before: page`；块 `break-inside: avoid`；`thead` 用 `table-header-group` 重复 |
| 省墨机制 | 背景默认不打印；`print-color-adjust: exact` 是请求，用户勾选才是开关 |
| JS 控制 | `window.print()` + `beforeprint`/`afterprint`；局部打印用隐藏 iframe（注意时序） |
| 单位 | 纸上用 `pt`/`mm`/`cm`，不用 `px` |

**记住三句话**：

1. **打印是"另一种媒体"：`@media print` 决定放什么，`@page` 决定纸长什么样，`break-*` 决定在哪断页。**
2. **背景色默认不打印——`exact` 只是请求，信息永远别只靠颜色表达。**
3. **局部打印用隐藏 iframe，先等渲染再 `print()`，`afterprint` 里再清理。**

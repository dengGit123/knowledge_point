### 一、概述

文件上传和下载是 Web 开发中的常见需求：用户上传头像、文档，下载报表、图片等。JavaWeb 中文件操作的核心问题是：**如何把二进制数据正确地通过 HTTP 传输**。

> 💡 **提示：** 文件上传下载的 HTTP 原理见 [[HTTP协议]] 中的 Content-Type 部分。本文聚焦 JavaWeb 中的具体实现。

| 你将学到 | 说明 |
| --- | --- |
| 文件上传原理 | multipart/form-data 格式 |
| Servlet 3.0 文件上传 | `@MultipartConfig` + `Part` |
| 文件下载原理 | Content-Disposition 头部 |
| 中文文件名处理 | 不同浏览器的编码差异 |
| 安全注意事项 | 文件大小、类型、路径安全 |

### 二、文件上传原理

#### 1. 表单要求

文件上传的表单**必须**满足两个条件：

```html
<!-- ✅ 正确的文件上传表单 -->
<form action="${pageContext.request.contextPath}/upload" method="post" enctype="multipart/form-data">
    <input type="text" name="username">
    <input type="file" name="avatar">
    <button type="submit">上传</button>
</form>
```

| 属性 | 要求 | 说明 |
| --- | --- | --- |
| `method` | 必须是 `post` | GET 没有请求体，传不了文件 |
| `enctype` | 必须是 `multipart/form-data` | 告诉浏览器用多部分格式编码 |

> ⚠️ **注意：** 如果 `enctype` 不是 `multipart/form-data`，`request.getParameter()` 取不到任何参数，文件也传不上去。

#### 2. multipart/form-data 格式

当表单设为 `multipart/form-data` 时，请求体变成这样：

```
POST /upload HTTP/1.1
Content-Type: multipart/form-data; boundary=----WebKitFormBoundaryABC123

------WebKitFormBoundaryABC123
Content-Disposition: form-data; name="username"

张三
------WebKitFormBoundaryABC123
Content-Disposition: form-data; name="avatar"; filename="photo.jpg"
Content-Type: image/jpeg

[二进制文件内容]
------WebKitFormBoundaryABC123--
```

每个表单字段之间用 `boundary` 分隔，文件字段会带上文件名和 Content-Type。

### 三、Servlet 3.0 文件上传

Servlet 3.0（Tomcat 7+）开始支持原生文件上传，无需第三方库（如 Apache Commons FileUpload）。

#### 1. 基本文件上传

```java
@WebServlet("/upload")
@MultipartConfig(  // ★ 必须加这个注解
    fileSizeThreshold = 1024 * 1024,   // 内存阈值：1MB（超过就写临时文件）
    maxFileSize = 10 * 1024 * 1024,    // 单个文件最大 10MB
    maxRequestSize = 50 * 1024 * 1024  // 整个请求最大 50MB
)
public class UploadServlet extends HttpServlet {

    @Override
    protected void doPost(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
        // 设置编码（防中文乱码）
        req.setCharacterEncoding("UTF-8");

        // ① 获取普通表单字段
        String username = req.getParameter("username");

        // ② 获取上传的文件（name="avatar" 的 file 控件）
        Part filePart = req.getPart("avatar");

        // ③ 获取文件信息
        String fileName = filePart.getSubmittedFileName();  // 原始文件名
        String contentType = filePart.getContentType();     // MIME 类型
        long fileSize = filePart.getSize();                 // 文件大小（字节）

        System.out.println("文件名：" + fileName);
        System.out.println("类型：" + contentType);
        System.out.println("大小：" + fileSize + " bytes");

        // ④ 保存到服务器
        String uploadPath = getServletContext().getRealPath("/uploads");
        // 确保目录存在
        new File(uploadPath).mkdirs();

        // 直接写入
        filePart.write(uploadPath + File.separator + fileName);

        // ⑤ 清理临时文件
        filePart.delete();

        resp.getWriter().write("上传成功：" + fileName);
    }
}
```

#### 2. 获取文件名（兼容写法）

`getSubmittedFileName()` 是 Servlet 3.1+ 的方法，3.0 需要从 Content-Disposition 头部解析：

```java
// 兼容 Servlet 3.0 的文件名获取方法
private String getFileName(Part part) {
    String header = part.getHeader("Content-Disposition");
    // 查找 filename="xxx"
    for (String cd : header.split(";")) {
        if (cd.trim().startsWith("filename")) {
            String fileName = cd.substring(cd.indexOf('=') + 1).trim().replace("\"", "");
            // 处理 IE 浏览器带路径的情况（如 C:\Users\xxx\photo.jpg）
            return fileName.substring(fileName.lastIndexOf('/') + 1)
                          .substring(fileName.lastIndexOf('\\') + 1);
        }
    }
    return null;
}
```

#### 3. 多文件上传

```java
@WebServlet("/upload/multi")
@MultipartConfig(maxFileSize = 10 * 1024 * 1024)
public class MultiUploadServlet extends HttpServlet {
    @Override
    protected void doPost(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
        String uploadPath = getServletContext().getRealPath("/uploads");
        new File(uploadPath).mkdirs();

        // 获取所有 Part（包括普通字段和文件）
        Collection<Part> parts = req.getParts();

        for (Part part : parts) {
            // 判断是文件还是普通字段（有 filename 就是文件）
            if (part.getSubmittedFileName() != null && !part.getSubmittedFileName().isEmpty()) {
                // 是文件，保存
                String fileName = part.getSubmittedFileName();
                part.write(uploadPath + File.separator + fileName);
                part.delete();
            } else {
                // 是普通字段，读取值
                String value = new String(part.getInputStream().readAllBytes(), "UTF-8");
                System.out.println(part.getName() + " = " + value);
            }
        }

        resp.getWriter().write("多文件上传成功");
    }
}
```

### 四、文件下载

#### 1. 基本文件下载

```java
@WebServlet("/download")
public class DownloadServlet extends HttpServlet {
    @Override
    protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws IOException {
        // ① 获取要下载的文件名
        String fileName = req.getParameter("file");
        if (fileName == null || fileName.isEmpty()) {
            resp.sendError(400, "缺少 file 参数");
            return;
        }

        // ② 获取文件的真实路径
        String filePath = getServletContext().getRealPath("/files/" + fileName);
        File file = new File(filePath);

        if (!file.exists()) {
            resp.sendError(404, "文件不存在");
            return;
        }

        // ③ 设置响应头
        resp.setContentType("application/octet-stream");  // 告诉浏览器这是二进制流
        resp.setHeader("Content-Disposition", "attachment;filename=" + fileName);  // 触发下载
        resp.setContentLengthLong(file.length());  // 文件大小（浏览器显示进度）

        // ④ 读取文件写入响应输出流
        try (InputStream in = new FileInputStream(file);
             OutputStream out = resp.getOutputStream()) {
            byte[] buf = new byte[4096];
            int len;
            while ((len = in.read(buf)) != -1) {
                out.write(buf, 0, len);
            }
        }
    }
}
```

#### 2. 处理中文文件名

不同浏览器对中文文件名的编码方式不同，需要根据 User-Agent 分别处理：

```java
private String encodeFileName(String fileName, HttpServletRequest req) throws UnsupportedEncodingException {
    String userAgent = req.getHeader("User-Agent");
    if (userAgent != null && (userAgent.contains("MSIE") || userAgent.contains("Trident") || userAgent.contains("Edge"))) {
        // IE / Edge 浏览器：URL 编码
        return URLEncoder.encode(fileName, "UTF-8").replace("+", "%20");
    } else {
        // Chrome、Firefox 等其他浏览器：RFC 5987
        return new String(fileName.getBytes("UTF-8"), "ISO-8859-1");
    }
}

// 使用
String encodedName = encodeFileName(fileName, req);
resp.setHeader("Content-Disposition", "attachment;filename=" + encodedName);
```

#### 3. 断点续传（了解）

大文件下载时支持断点续传，需要处理 `Range` 请求头：

```java
@WebServlet("/download/resume")
public class ResumeDownloadServlet extends HttpServlet {
    @Override
    protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws IOException {
        String filePath = getServletContext().getRealPath("/files/bigfile.zip");
        File file = new File(filePath);
        long fileLength = file.length();

        // 解析 Range 头部（如 bytes=1024-2047）
        String rangeHeader = req.getHeader("Range");
        long start = 0, end = fileLength - 1;

        if (rangeHeader != null && rangeHeader.startsWith("bytes=")) {
            String[] range = rangeHeader.substring(6).split("-");
            start = Long.parseLong(range[0]);
            if (range.length > 1 && !range[1].isEmpty()) {
                end = Long.parseLong(range[1]);
            }
            resp.setStatus(206);  // Partial Content
        } else {
            resp.setStatus(200);
        }

        long contentLength = end - start + 1;

        resp.setContentType("application/octet-stream");
        resp.setHeader("Content-Range", "bytes " + start + "-" + end + "/" + fileLength);
        resp.setHeader("Accept-Ranges", "bytes");
        resp.setContentLengthLong(contentLength);

        // 使用 RandomAccessFile 跳转到指定位置
        try (RandomAccessFile raf = new RandomAccessFile(file, "r");
             OutputStream out = resp.getOutputStream()) {
            raf.seek(start);
            byte[] buf = new byte[4096];
            long remaining = contentLength;
            int len;
            while (remaining > 0 && (len = raf.read(buf, 0, (int) Math.min(buf.length, remaining))) != -1) {
                out.write(buf, 0, len);
                remaining -= len;
            }
        }
    }
}
```

### 五、文件上传的安全注意事项

文件上传是 Web 安全的高风险点，必须做好防护：

| 风险 | 防护措施 |
| --- | --- |
| **文件过大导致 OOM** | 设置 `maxFileSize` 和 `maxRequestSize` |
| **恶意文件（木马）** | 校验文件类型（MIME + 文件头魔数） |
| **文件名注入** | 过滤路径分隔符（`../`） |
| **同名文件覆盖** | 生成唯一文件名（UUID + 时间戳） |
| **文件存储位置** | 存放在 Web 应用外部，避免直接访问 |

#### 安全的文件上传示例

```java
@WebServlet("/upload/safe")
@MultipartConfig(maxFileSize = 10 * 1024 * 1024)
public class SafeUploadServlet extends HttpServlet {

    // 允许的文件类型（MIME）
    private static final Set<String> ALLOWED_TYPES = Set.of(
        "image/jpeg", "image/png", "image/gif", "application/pdf"
    );

    @Override
    protected void doPost(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException {
        Part filePart = req.getPart("file");
        String fileName = filePart.getSubmittedFileName();

        // ① 校验文件类型
        if (!ALLOWED_TYPES.contains(filePart.getContentType())) {
            resp.sendError(400, "不支持的文件类型");
            return;
        }

        // ② 校验文件大小
        if (filePart.getSize() > 10 * 1024 * 1024) {
            resp.sendError(400, "文件过大");
            return;
        }

        // ③ 生成唯一文件名（防覆盖 + 防注入）
        String ext = fileName.substring(fileName.lastIndexOf("."));
        String uniqueName = UUID.randomUUID().toString().replace("-", "") + ext;

        // ④ 保存到 Web 应用外部目录（更安全）
        String uploadDir = "/data/uploads";  // 配置在外部
        new File(uploadDir).mkdirs();
        filePart.write(uploadDir + File.separator + uniqueName);
        filePart.delete();

        // ⑤ 返回文件访问路径（通过专门的下载 Servlet 访问）
        resp.getWriter().write("上传成功，文件ID：" + uniqueName);
    }
}
```

> ⚠️ **注意：** 永远不要信任用户上传的文件。生产环境建议：
> - 文件存储在**对象存储**（如阿里云 OSS、AWS S3）
> - 文件访问通过**专门的下载接口**（不直接暴露路径）
> - 图片处理（压缩、水印）后再存储

### 六、Base64 方式上传（前后端分离场景）

前后端分离项目中，文件常以 Base64 编码的 JSON 传输：

```java
@WebServlet("/api/upload/base64")
public class Base64UploadServlet extends HttpServlet {
    @Override
    protected void doPost(HttpServletRequest req, HttpServletResponse resp) throws IOException {
        // 读取 JSON 请求体
        BufferedReader reader = req.getReader();
        StringBuilder sb = new StringBuilder();
        String line;
        while ((line = reader.readLine()) != null) {
            sb.append(line);
        }

        // 解析 JSON（用 Jackson）
        ObjectMapper mapper = new ObjectMapper();
        JsonNode node = mapper.readTree(sb.toString());
        String base64Data = node.get("file").asText();  // "data:image/png;base64,iVBORw0KGgo..."
        String fileName = node.get("fileName").asText();

        // 去掉 Base64 前缀（data:image/png;base64,）
        String base64Image = base64Data.split(",")[1];

        // 解码
        byte[] fileBytes = Base64.getDecoder().decode(base64Image);

        // 保存
        String uploadPath = "/data/uploads";
        String uniqueName = UUID.randomUUID().toString() + "_" + fileName;
        Files.write(Paths.get(uploadPath, uniqueName), fileBytes);

        resp.setContentType("application/json;charset=UTF-8");
        resp.getWriter().write("{\"code\":200,\"fileId\":\"" + uniqueName + "\"}");
    }
}
```

### 七、常见问题与注意事项

| 问题 | 原因 | 解决 |
| --- | --- | --- |
| 上传报 500 | 没加 `@MultipartConfig` | 在 Servlet 上加 `@MultipartConfig` |
| 上传文件为 0 字节 | 文件超过 `maxFileSize` | 增大限制或提示用户 |
| 中文文件名乱码 | 浏览器编码方式不同 | 根据 User-Agent 分别处理 |
| 下载时浏览器直接打开 | 没设 `Content-Disposition: attachment` | 加上这个响应头 |
| 文件保存失败 | 目录不存在 / 权限不足 | `mkdirs()` 创建目录，检查权限 |
| 临时文件堆积 | 没调用 `part.delete()` | 上传完成后清理临时文件 |

> ⚠️ **注意：** 文件上传后一定要调用 `part.delete()` 清理 Tomcat 生成的临时文件，否则会占用磁盘空间。

### 八、总结

- 文件上传表单必须 `method="post"` + `enctype="multipart/form-data"`
- Servlet 3.0+ 用 `@MultipartConfig` + `Part` 处理上传
- 文件下载设 `Content-Disposition: attachment` 触发下载
- 中文文件名根据 User-Agent 分别处理（IE 用 URLEncoder，其他用 ISO-8859-1）
- 安全要点：校验类型、限制大小、生成唯一文件名、存外部目录
- 大文件下载支持断点续传（处理 `Range` 头部）

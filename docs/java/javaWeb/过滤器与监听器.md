### 一、概述

> 📖 [Filter（Oracle）](https://docs.oracle.com/javaee/7/api/javax/servlet/Filter.html) ｜ [ServletContextListener（Oracle）](https://docs.oracle.com/javaee/7/api/javax/servlet/ServletContextListener.html)

**Filter（过滤器）** 和 **Listener（监听器）** 是 JavaWeb 的三大组件之二（第三个是 Servlet），它们的作用是：

- **Filter**：在请求到达 Servlet **之前**和响应返回浏览器 **之前**做拦截处理（如编码、权限校验）
- **Listener**：监听 Web 应用中的事件（如应用启动、Session 创建），在事件发生时执行回调

大白话：Filter 是「安检门」——进出都要过一遍；Listener 是「监控摄像头」——看到特定事件就触发动作。

| 你将学到 | 说明 |
| --- | --- |
| Filter 生命周期 | 创建、过滤、销毁 |
| FilterChain 过滤器链 | 多个 Filter 的执行顺序 |
| Filter 应用场景 | 编码、权限、日志、压缩 |
| Listener 类型 | 三类监听器 |
| 实际应用 | 登录拦截、在线人数统计 |

### 二、Filter 过滤器

#### 1. Filter 的工作原理

```
浏览器请求 → ① Filter1 → ② Filter2 → ③ Servlet → ④ Filter2 → ⑤ Filter1 → 浏览器响应
            (前置处理)   (前置处理)   (业务)    (后置处理)   (后置处理)
```

Filter 可以拦截请求和响应，在请求到达 Servlet 前后、响应返回浏览器前后执行逻辑。

#### 2. Filter 接口

```java
public interface Filter {
    void init(FilterConfig filterConfig) throws ServletException;  // 初始化
    void doFilter(ServletRequest request, ServletResponse response, FilterChain chain);  // 过滤
    void destroy();  // 销毁
}
```

#### 3. 编写一个 Filter

```java
@WebFilter("/*")  // 拦截所有请求
public class EncodingFilter implements Filter {

    private String encoding = "UTF-8";

    @Override
    public void init(FilterConfig filterConfig) throws ServletException {
        // 读取初始化参数（可选）
        String configEncoding = filterConfig.getInitParameter("encoding");
        if (configEncoding != null) {
            this.encoding = configEncoding;
        }
        System.out.println("EncodingFilter 初始化");
    }

    @Override
    public void doFilter(ServletRequest request, ServletResponse response, FilterChain chain)
            throws IOException, ServletException {
        // ① 前置处理（请求到达 Servlet 之前）
        request.setCharacterEncoding(encoding);
        response.setCharacterEncoding(encoding);
        System.out.println("[Filter] 请求编码已设置：" + encoding);

        // ② 放行（调用 chain.doFilter 才会继续往下走）
        chain.doFilter(request, response);

        // ③ 后置处理（响应返回浏览器之前）
        System.out.println("[Filter] 响应已返回");
    }

    @Override
    public void destroy() {
        System.out.println("EncodingFilter 销毁");
    }
}
```

> ⚠️ **注意：** `chain.doFilter()` **必须调用**，否则请求会被拦截在此，Servlet 不会执行。

#### 4. Filter 的配置

**方式一：注解配置**

```java
@WebFilter(
    filterName = "encodingFilter",
    urlPatterns = "/*",  // 拦截路径
    initParams = {
        @WebInitParam(name = "encoding", value = "UTF-8")
    }
)
```

**方式二：web.xml 配置**

```xml
<filter>
    <filter-name>encodingFilter</filter-name>
    <filter-class>com.example.EncodingFilter</filter-class>
    <init-param>
        <param-name>encoding</param-name>
        <param-value>UTF-8</param-value>
    </init-param>
</filter>
<filter-mapping>
    <filter-name>encodingFilter</filter-name>
    <url-pattern>/*</url-pattern>
</filter-mapping>
```

#### 5. Filter 的拦截路径

| 配置 | 说明 | 示例 |
| --- | --- | --- |
| `/*` | 拦截所有请求 | 编码过滤器 |
| `/admin/*` | 拦截 admin 下的所有请求 | 权限过滤器 |
| `*.do` | 拦截所有 `.do` 结尾的请求 | 旧项目常见 |
| `/login` | 只拦截精确路径 | 少见 |

#### 6. FilterChain 过滤器链

当多个 Filter 拦截同一个请求时，它们组成一条**过滤器链**：

```java
@WebFilter("/*")
public class LogFilter implements Filter {
    @Override
    public void doFilter(ServletRequest request, ServletResponse response, FilterChain chain)
            throws IOException, ServletException {
        long start = System.currentTimeMillis();
        chain.doFilter(request, response);  // 放行
        long end = System.currentTimeMillis();
        System.out.println("请求耗时：" + (end - start) + "ms");
    }
}

@WebFilter("/*")
public class AuthFilter implements Filter {
    @Override
    public void doFilter(ServletRequest request, ServletResponse response, FilterChain chain)
            throws IOException, ServletException {
        HttpServletRequest req = (HttpServletRequest) request;
        if (req.getSession(false) == null) {
            ((HttpServletResponse) response).sendRedirect("/login");
            return;  // 不放行，直接返回
        }
        chain.doFilter(request, response);  // 已登录，放行
    }
}
```

**执行顺序：** 按 Filter 的注册顺序（注解按类名字母顺序，web.xml 按配置顺序）依次执行前置处理，Servlet 执行后，**反向**执行后置处理。

```
请求 → LogFilter 前置 → AuthFilter 前置 → Servlet → AuthFilter 后置 → LogFilter 后置 → 响应
```

### 三、Filter 实际应用场景

#### 场景 1：统一编码（最常用）

```java
@WebFilter("/*")
public class CharacterEncodingFilter implements Filter {
    @Override
    public void doFilter(ServletRequest req, ServletResponse resp, FilterChain chain)
            throws IOException, ServletException {
        req.setCharacterEncoding("UTF-8");
        resp.setContentType("text/html;charset=UTF-8");
        chain.doFilter(req, resp);
    }
}
```

#### 场景 2：登录拦截

```java
@WebFilter(urlPatterns = {"/*"},
    initParams = @WebInitParam(name = "exclusions", value = "/login,/css/,/js/,/images/"))
public class LoginFilter implements Filter {
    private String[] excludedUrls;

    @Override
    public void init(FilterConfig filterConfig) {
        String exclusions = filterConfig.getInitParameter("exclusions");
        if (exclusions != null) {
            excludedUrls = exclusions.split(",");
        }
    }

    @Override
    public void doFilter(ServletRequest req, ServletResponse resp, FilterChain chain)
            throws IOException, ServletException {
        HttpServletRequest request = (HttpServletRequest) req;
        HttpServletResponse response = (HttpServletResponse) resp;

        String uri = request.getRequestURI();

        // 检查是否在排除列表中
        for (String excluded : excludedUrls) {
            if (uri.contains(excluded)) {
                chain.doFilter(req, resp);
                return;
            }
        }

        // 检查是否已登录
        HttpSession session = request.getSession(false);
        if (session != null && session.getAttribute("loginUser") != null) {
            chain.doFilter(req, resp);  // 已登录，放行
        } else {
            response.sendRedirect(request.getContextPath() + "/login");  // 未登录，重定向
        }
    }
}
```

#### 场景 3：跨域处理（CORS）

```java
@WebFilter("/*")
public class CorsFilter implements Filter {
    @Override
    public void doFilter(ServletRequest req, ServletResponse resp, FilterChain chain)
            throws IOException, ServletException {
        HttpServletResponse response = (HttpServletResponse) resp;
        HttpServletRequest request = (HttpServletRequest) req;

        // 允许跨域访问的域名
        response.setHeader("Access-Control-Allow-Origin", "*");
        response.setHeader("Access-Control-Allow-Methods", "GET,POST,PUT,DELETE,OPTIONS");
        response.setHeader("Access-Control-Allow-Headers", "Content-Type,Authorization");

        // 预检请求直接返回
        if ("OPTIONS".equalsIgnoreCase(request.getMethod())) {
            return;
        }

        chain.doFilter(req, resp);
    }
}
```

#### 场景 4：日志记录

```java
@WebFilter("/*")
public class LogFilter implements Filter {
    @Override
    public void doFilter(ServletRequest req, ServletResponse resp, FilterChain chain)
            throws IOException, ServletException {
        HttpServletRequest request = (HttpServletRequest) req;

        // 记录请求信息
        String uri = request.getRequestURI();
        String method = request.getMethod();
        String ip = request.getRemoteAddr();
        long start = System.currentTimeMillis();

        chain.doFilter(req, resp);

        long duration = System.currentTimeMillis() - start;
        System.out.printf("[%s] %s %s from %s, 耗时 %dms%n", method, uri, ip, duration);
    }
}
```

### 四、Listener 监听器

#### 1. Listener 的作用

Listener 用于监听 Web 应用中的事件，常见的三类监听器：

| 类别 | 接口 | 监听内容 |
| --- | --- | --- |
| **ServletContext** | `ServletContextListener` | 应用启动/关闭 |
| | `ServletContextAttributeListener` | context 域属性增删改 |
| **HttpSession** | `HttpSessionListener` | Session 创建/销毁 |
| | `HttpSessionAttributeListener` | session 域属性增删改 |
| | `HttpSessionBindingListener` | 对象绑定/解绑到 Session |
| **ServletRequest** | `ServletRequestListener` | 请求创建/销毁 |
| | `ServletRequestAttributeListener` | request 域属性增删改 |

#### 2. ServletContextListener — 应用生命周期监听

最常用，用于应用启动时加载配置、初始化资源，关闭时释放资源：

```java
@WebListener
public class AppContextListener implements ServletContextListener {

    @Override
    public void contextInitialized(ServletContextEvent sce) {
        // 应用启动时执行（相当于「开机自启」）
        System.out.println("Web 应用启动");

        ServletContext context = sce.getServletContext();

        // 加载配置文件
        String appName = context.getInitParameter("appName");
        context.setAttribute("appName", appName);

        // 初始化数据库连接池
        // DataSource ds = createDataSource();
        // context.setAttribute("dataSource", ds);

        // 统计在线人数
        context.setAttribute("onlineCount", 0);
    }

    @Override
    public void contextDestroyed(ServletContextEvent sce) {
        // 应用关闭时执行（相当于「关机清理」）
        System.out.println("Web 应用关闭");

        // 释放资源：关闭连接池、保存数据等
    }
}
```

#### 3. HttpSessionListener — Session 生命周期监听

常用于统计在线人数：

```java
@WebListener
public class OnlineCountListener implements HttpSessionListener {

    @Override
    public void sessionCreated(HttpSessionEvent se) {
        // Session 创建时（用户首次访问）
        ServletContext context = se.getSession().getServletContext();
        Integer count = (Integer) context.getAttribute("onlineCount");
        context.setAttribute("onlineCount", count == null ? 1 : count + 1);
        System.out.println("在线人数：" + context.getAttribute("onlineCount"));
    }

    @Override
    public void sessionDestroyed(HttpSessionEvent se) {
        // Session 销毁时（超时或 invalidate）
        ServletContext context = se.getSession().getServletContext();
        Integer count = (Integer) context.getAttribute("onlineCount");
        if (count != null && count > 0) {
            context.setAttribute("onlineCount", count - 1);
        }
        System.out.println("在线人数：" + context.getAttribute("onlineCount"));
    }
}
```

#### 4. ServletRequestListener — 请求生命周期监听

```java
@WebListener
public class RequestListener implements ServletRequestListener {

    @Override
    public void requestInitialized(ServletRequestEvent sre) {
        // 请求开始时
        System.out.println("请求开始：" + ((HttpServletRequest) sre.getServletRequest()).getRequestURI());
    }

    @Override
    public void requestDestroyed(ServletRequestEvent sre) {
        // 请求结束时
        System.out.println("请求结束");
    }
}
```

#### 5. HttpSessionBindingListener — 对象绑定监听

这个接口**不需要** `@WebListener`，由被存入 Session 的类自己实现：

```java
public class User implements HttpSessionBindingListener, Serializable {

    private String name;

    @Override
    public void valueBound(HttpSessionBindingEvent event) {
        // 对象被放入 Session 时自动调用
        System.out.println(name + " 被存入 Session");
    }

    @Override
    public void valueUnbound(HttpSessionBindingEvent event) {
        // 对象从 Session 移除时自动调用
        System.out.println(name + " 从 Session 移除");
    }
}
```

### 五、Filter 与 Listener 的执行顺序

```
应用启动
  ↓
Listener.contextInitialized()  ← 监听器先执行
  ↓
Filter.init()                  ← 过滤器初始化
  ↓
... 处理请求 ...
  ↓
Filter.doFilter()              ← 每次请求都执行
  ↓
应用关闭
  ↓
Filter.destroy()
  ↓
Listener.contextDestroyed()    ← 监听器最后执行
```

### 六、JavaWeb 三大组件对比

| 组件 | 作用 | 执行时机 | 配置方式 |
| --- | --- | --- | --- |
| **Servlet** | 处理请求和响应 | 每次请求 | `@WebServlet` |
| **Filter** | 拦截请求和响应 | 每次请求（可配置路径） | `@WebFilter` |
| **Listener** | 监听事件 | 事件触发时（启动/关闭/创建/销毁） | `@WebListener` |

### 七、常见问题与注意事项

| 问题 | 原因 | 解决 |
| --- | --- | --- |
| Filter 没生效 | 没加 `@WebFilter` 或路径不匹配 | 检查注解和 URL 模式 |
| Filter 死循环 | 重定向的路径也被同一个 Filter 拦截 | 排除重定向目标路径 |
| Filter 执行顺序不确定 | 注解配置的 Filter 顺序不确定 | 用 web.xml 配置控制顺序 |
| Listener 没生效 | 没加 `@WebListener` | 检查注解 |
| 在线人数统计不准 | Session 超时时间太长 | 合理设置 Session 超时 |

> ⚠️ **注意：** 多个 Filter 的执行顺序：
> - **web.xml 配置**：按 `<filter-mapping>` 的声明顺序
> - **注解配置**：默认按**类名字母顺序**（不确定！需要明确顺序时用 web.xml）

---

### 八、总结

- **Filter** 拦截请求/响应，用于编码、权限、日志、跨域等通用处理
- `chain.doFilter()` **必须调用**，否则请求被拦截
- **Listener** 监听事件，用于初始化资源、统计在线人数等
- 三大组件：Servlet（处理请求）、Filter（拦截请求）、Listener（监听事件）
- Filter 执行顺序：web.xml 按配置顺序，注解按类名字母顺序
- 实际项目：编码 Filter + 登录拦截 Filter + 在线人数 Listener 是最常见的组合

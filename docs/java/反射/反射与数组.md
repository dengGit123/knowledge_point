# 反射与数组——java.lang.reflect.Array

> 📖 官方文档：[Array (Java SE 21)](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/reflect/Array.html) ｜ [Oracle 反射教程 - Arrays and Enumerated Types](https://docs.oracle.com/javase/tutorial/reflect/special/index.html)

## 一、概述

数组在 Java 里是特殊的对象——它没有自己的类源码，却有独立的 `Class` 对象（如 `int[].class`）。当你需要在**运行时才知道元素类型和长度**的场景下创建数组、或以通用方式读写任意数组的元素时，普通的 `new T[n]`（泛型擦除后不可用）和 `arr[i]`（写死具体数组类型）都不够用了。

`java.lang.reflect.Array` 类就是为此提供的**数组反射工具类**：全部是静态方法，支持动态创建数组（含多维）、按索引读写任意元素、查询长度。

> 💡 **类比：** 普通数组操作像「拿着具体型号的钥匙开具体的锁」；`Array` 工具类像「一把万能钥匙 + 一个长度测量仪」，不关心数组具体是什么类型，通吃。

## 二、数组的 Class 对象

先认识数组的反射身份：

```java
Class<int[]> c1 = int[].class;
Class<String[]> c2 = String[].class;
Class<int[][]> c3 = int[][].class;

// 数组 Class 的两个关键 API（Java 12+ 的 componentType/arrayType，老版本为 getComponentType）
System.out.println(c1.getComponentType()); // int —— 数组的元素类型（老 API，各版本都有）
System.out.println(String[].class.getComponentType()); // class java.lang.String

String[] arr = {"a", "b"};
System.out.println(arr.getClass().isArray());     // true —— 判断是否数组类型
System.out.println(arr.getClass().getName());     // [Ljava.lang.String; —— 二进制名称
```

| 表达式 | `getName()` 结果 |
| ---- | ---- |
| `String[].class` | `[Ljava.lang.String;` |
| `int[].class` | `[I` |
| `int[][].class` | `[[I` |
| `User[].class` | `[Lcom.example.User;` |

规则：一维数组是 `[` + 元素类型描述符；基本类型有单字母描述符（`I` 是 int、`J` 是 long、`Z` 是 boolean……）；引用类型是 `[L全限定名;`。这些字符串可以直接回传给 `Class.forName()`。

## 三、动态创建数组

```java
import java.lang.reflect.Array;

public class Demo {
    public static void main(String[] args) {
        // 一维数组：newInstance(元素类型, 长度)
        Object arr1 = Array.newInstance(int.class, 5);
        System.out.println(arr1.getClass());        // class [I
        System.out.println(Array.getLength(arr1));  // 5

        // 引用类型数组
        Object arr2 = Array.newInstance(String.class, 3);
        System.out.println(arr2.getClass());        // class [Ljava.lang.String;

        // 多维数组：newInstance(元素类型, 各维长度...)
        Object matrix = Array.newInstance(int.class, 3, 4);
        System.out.println(matrix.getClass());      // class [[I
        System.out.println(Array.getLength(matrix)); // 3 —— 第一维长度
    }
}
```

官方 javadoc 的签名与语义：

- `Array.newInstance(Class<?> componentType, int length)`：创建指定元素类型、指定长度的一维数组
- `Array.newInstance(Class<?> componentType, int... dimensions)`：创建多维数组，每个维度一个长度；**传入的维度数决定数组维数**，如 `dimensions = {3, 4}` 生成 `int[3][4]`
- 返回值都是 `Object`（因为编译期不知道具体数组类型），使用时要强转或配合 `Array.get/set`

> ⚠️ **注意：** 多维数组的 `componentType` 参数是**最内层元素类型**：`Array.newInstance(int.class, 3, 4)` 创建的是 `int[3][4]`，不是 `int[3][]` 里的某一维。负长度会抛 `NegativeArraySizeException`。

## 四、按索引读写元素

```java
import java.lang.reflect.Array;

public class Demo2 {
    public static void main(String[] args) {
        // 通用写入
        Object arr = Array.newInstance(int.class, 3);
        Array.setInt(arr, 0, 10);       // 等价于 arr[0] = 10（类型化写法）
        Array.set(arr, 1, 20);          // 通用写法：基本类型自动装箱

        // 通用读取
        Object v0 = Array.get(arr, 0);  // 返回 Object，基本类型装箱为 Integer
        int v1 = Array.getInt(arr, 1);  // 类型化读法
        System.out.println(v0 + ", " + v1); // 10, 20

        // 长度
        System.out.println(Array.getLength(arr)); // 3

        // 遍历任意数组（不知道具体类型也能遍历）
        String[] names = {"张三", "李四", "王五"};
        printAll(names);
    }

    /** ✅ 通吃任意数组的打印方法 */
    static void printAll(Object array) {
        if (array == null || !array.getClass().isArray()) {
            System.out.println("不是数组");
            return;
        }
        int len = Array.getLength(array);
        for (int i = 0; i < len; i++) {
            System.out.println("[" + i + "] = " + Array.get(array, i));
        }
    }
}
```

`Array.get/set` 与类型化方法的关系，与 `Field` 一致：

| 方法 | 说明 |
| ---- | ---- |
| `get(array, index)` / `set(array, index, value)` | 通用读写，基本类型自动装/拆箱 |
| `getInt` / `setInt`、`getLong` / `setLong`、`getBoolean` / `setBoolean` 等 | 基本类型专用，免装箱 |
| `getLength(array)` | 数组长度，等价于 `array.length` |
| 加宽允许、收窄抛异常 | 官方语义：读写允许加宽转换，收窄抛 `IllegalArgumentException` |

## 五、综合示例：泛型版的「指定长度数组复制」

写一个运行时才知道元素类型的数组扩容工具（类似 `Arrays.copyOf` 的原理）：

```java
import java.lang.reflect.Array;
import java.util.Arrays;

public class ArrayGrow {
    /** 任意类型数组扩容：新长度 = 原长度 * 2 */
    @SuppressWarnings("unchecked")
    public static <T> T grow(T array) {
        Class<?> componentType = array.getClass().getComponentType();
        int oldLen = Array.getLength(array);

        // 运行时按元素类型创建新数组
        Object newArr = Array.newInstance(componentType, oldLen * 2);

        // 逐个复制旧元素（真实实现用 System.arraycopy 更快，这里演示 Array API）
        for (int i = 0; i < oldLen; i++) {
            Array.set(newArr, i, Array.get(array, i));
        }
        return (T) newArr;
    }

    public static void main(String[] args) {
        String[] names = {"a"};
        String[] bigger = grow(names);
        System.out.println(bigger.length);  // 2

        int[] nums = {1, 2, 3};
        int[] bigger2 = grow(nums);
        System.out.println(Arrays.toString(bigger2)); // [1, 2, 3, 0, 0, 0]
    }
}
```

## 六、注意事项

1. **`Object` 类型数组 ≠ 数组对象**：`Object[]` 本身是数组，可以 `Array.get`；但单个 `Object` 不是。通用方法里先 `clazz.isArray()` 判断再操作。
2. **返回值都是 `Object`**：`Array.newInstance`/`get` 返回 `Object`，元素读取后基本类型已装箱；需要按 `getComponentType()` 判断真实类型后再转型。
3. **越界与空指针照常抛**：索引越界抛 `ArrayIndexOutOfBoundsException`，数组引用为 `null` 抛 `NullPointerException`——反射不豁免这些基础规则。
4. **性能**：`Array.get/set` 有装箱与类型检查开销；明确知道类型时直接用原生语法。这类 API 主要服务于「类型未知」的框架场景。
5. **泛型数组的正规姿势**：业务代码里想创建泛型数组 `T[]`，标准做法是 `Array.newInstance(componentType, n)` 后强转（如 `Arrays.copyOf` 内部的做法），而不是 `(T[]) new Object[n]`——后者运行时不是 `T[]` 类型，存入集合、返回给调用方时可能出 `ClassCastException`。

## 七、使用场景

| 场景 | 说明 |
| ---- | ---- |
| 集合转数组 | `ArrayList.toArray()` 内部即反射创建「元素类型与原集合一致的数组」 |
| 可变参数适配 | 框架把参数列表动态组装成数组传给 `Method.invoke` |
| 多维矩阵处理 | 数学/图形库运行时按维度参数创建矩阵数组 |
| 通用序列化 | JSON 框架序列化数组类型字段：`isArray()` 判断 + `Array.getLength` + 逐元素处理 |
| 泛型工具方法 | `<T> T[] newArray(Class<T> type, int len)` 这类类型安全的数组工厂 |

## 八、总结

- `java.lang.reflect.Array` 是数组的反射工具类，全静态方法：`newInstance` 动态创建（含多维）、`getLength` 查长度、`get`/`set` 及类型化变体按索引读写。
- 数组类型的 `Class` 对象用 `isArray()` 判断、`getComponentType()` 取元素类型、`getName()` 得到 `[Ljava.lang.String;` 这类二进制名称（可回传 `Class.forName`）。
- 官方转换语义：允许加宽、禁止收窄，收窄抛 `IllegalArgumentException`。
- 核心价值在「运行时才知道元素类型」：泛型数组创建、集合转数组、通用序列化；性能敏感且类型已知的业务代码直接用原生数组语法。

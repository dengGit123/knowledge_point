# 类型转换（自动转换与强制转换）

> 📖 [Java Language Specification — Conversions](https://docs.oracle.com/javase/specs/jls/se17/html/jls-5.html)

## 一、概述

Java 是强类型语言，不同类型之间的转换需要遵循特定规则。类型转换分为两大类：

| 转换类型 | 说明 | 安全性 | 是否需要显式声明 |
| --- | --- | --- | --- |
| **自动类型转换**（隐式） | 小范围 → 大范围 | 安全，无精度损失 | 不需要 |
| **强制类型转换**（显式） | 大范围 → 小范围 | 可能损失精度 | 需要 |

## 二、自动类型转换（隐式转换）

### 1. 转换规则

当满足以下两个条件时，Java 会自动进行类型转换：

1. **两种类型兼容**（都是数值类型）
2. **目标类型范围更大**

```
byte → short → int → long → float → double
       char ↗
```

> 💡 **记忆口诀：** 箭头方向就是自动转换方向，小类型可以自动变成大类型。

### 2. 转换示例

```java
// 整数类型之间的自动转换
byte b = 10;
short s = b;        // byte → short ✅
int i = s;          // short → int ✅
long l = i;         // int → long ✅

// 整数 → 浮点的自动转换
float f = l;        // long → float ✅（可能损失精度）
double d = f;       // float → double ✅

// char 的自动转换
char c = 'A';
int code = c;       // char → int ✅（得到 Unicode 码点 65）

// 表达式中的自动提升
byte a = 1;
byte b2 = 2;
// byte sum = a + b2;  // ❌ 编译错误：byte 运算结果为 int
int sum = a + b2;      // ✅ 结果是 int
```

### 3. long 与 float 的特殊关系

`long`（8 字节）可以自动转 `float`（4 字节），虽然 `float` 字节数更少，但**表示范围更大**（浮点数的指数表示法）：

```java
long big = 1234567890123L;
float f = big;      // ✅ 自动转换，但可能损失精度
System.out.println(f);  // 1.23456795E12  ⚠️ 精度丢失
```

## 三、强制类型转换（显式转换）

### 1. 转换语法

当需要将大范围类型转为小范围类型时，必须使用强制转换：

```java
目标类型 变量 = (目标类型) 被转换的值;
```

### 2. 转换示例

```java
// 浮点 → 整数：直接截断小数
double d = 3.99;
int i = (int) d;          // 3  ⚠️ 不是四舍五入，直接截断
long l = Math.round(d);   // 4  ✅ 四舍五入

// 大范围整数 → 小范围整数：高位截断
int big = 256;
byte small = (byte) big;  // 0  ⚠️ 溢出：256 的二进制 100000000，截断后 8 位为 0

int negative = -129;
byte b = (byte) negative; // 127  ⚠️ 溢出：绕回到另一端

// double → float：可能损失精度或变成无穷大
double d2 = 1.7976931348623157E+308;
float f2 = (float) d2;    // Infinity  ⚠️ 超出 float 范围

// int → char：取低 16 位
int code = 65;
char c = (char) code;     // 'A'
```

### 3. 强制转换的风险

| 风险 | 说明 | 示例 |
| --- | --- | --- |
| **溢出** | 目标类型存不下，值会"绕回" | `(byte) 200` → `-56` |
| **精度损失** | 浮点转整数丢失小数 | `(int) 3.9` → `3` |
| **变为无穷大** | 超出浮点范围 | `(float) 1e308` → `Infinity` |

## 四、表达式中的类型提升

### 1. 二元运算提升规则

当运算符两侧的类型不同时，Java 会自动将操作数提升为较大的类型：

```
运算数 1 类型    运算数 2 类型    结果类型
─────────────────────────────────────────
byte/short/int    byte/short/int   int
任意含 long       ...              long
任意含 float      ...              float
任意含 double     ...              double
```

```java
int i = 100;
long l = 1000L;
float f = 3.14f;
double d = 3.14;

System.out.println(i + l);    // long（int 被提升为 long）
System.out.println(i + f);    // float（int 被提升为 float）
System.out.println(i + d);    // double（int 被提升为 double）
```

### 2. 特殊类型：byte、short、char 的运算

`byte`、`short`、`char` 参与运算时，**一律先提升为 `int`**：

```java
byte a = 1;
byte b = 2;
// byte c = a + b;            // ❌ 结果是 int，不能直接赋给 byte
int c = a + b;                // ✅

char ch = 'A';
// char result = ch + 1;      // ❌ 结果是 int
char result = (char) (ch + 1); // ✅ 'B'
```

> ⚠️ **这是 Java 面试高频考点**：`byte + byte = int`，`char + char = int`。

### 3. 赋值时的自动转换

赋值时，只要目标类型能容纳源值，就自动转换：

```java
// ✅ 自动转换
int i = 'A';          // char → int
long l = 100;         // int → long
double d = 3.14f;     // float → double

// ❌ 需要强制转换
// int j = 100L;      // long → int 不允许
int j = (int) 100L;   // ✅
```

## 五、字符串与其他类型的转换

### 1. 其他类型 → String

```java
// 方式一：字符串拼接（最简单）
String s1 = "" + 123;         // "123"
String s2 = "" + true;        // "true"
String s3 = "" + 3.14;        // "3.14"

// 方式二：String.valueOf()（推荐）
String s4 = String.valueOf(123);    // "123"
String s5 = String.valueOf(true);   // "true"
String s6 = String.valueOf('A');    // "A"

// 方式三：包装类的 toString()
String s7 = Integer.toString(123);  // "123"
String s8 = Double.toString(3.14);  // "3.14"
```

### 2. String → 其他类型

```java
// 字符串 → 整数
int i = Integer.parseInt("128");       // 128
long l = Long.parseLong("123456789");  // 123456789
byte b = Byte.parseByte("100");        // 100

// 字符串 → 浮点数
float f = Float.parseFloat("3.14");    // 3.14
double d = Double.parseDouble("3.14"); // 3.14

// 字符串 → 布尔
boolean flag = Boolean.parseBoolean("true");  // true
boolean flag2 = Boolean.parseBoolean("TRUE"); // true（不区分大小写）
boolean flag3 = Boolean.parseBoolean("yes");  // false（只认 true）

// 字符串 → char
char c = "ABC".charAt(0);  // 'A'
```

> ⚠️ **注意：** 解析失败会抛出 `NumberFormatException`：

```java
// int x = Integer.parseInt("abc");  // ❌ 抛出 NumberFormatException
// int y = Integer.parseInt("");     // ❌ 空字符串也抛异常
// int z = Integer.parseInt(null);   // ❌ null 也抛异常

// ✅ 安全做法：使用 try-catch 或先校验
try {
    int x = Integer.parseInt(userInput);
} catch (NumberFormatException e) {
    System.out.println("输入的不是有效数字");
}
```

## 六、溢出检测（Java 8+）

Java 8 在 `Math` 类中提供了带溢出检测的运算方法：

```java
// 溢出时抛出 ArithmeticException，而不是静默回绕
int safe = Math.addExact(Integer.MAX_VALUE, 1);      // 抛出异常
int safe2 = Math.multiplyExact(100000, 100000);       // 抛出异常
int safe3 = Math.subtractExact(Integer.MIN_VALUE, 1); // 抛出异常

// 无符号运算
long unsigned = Integer.toUnsignedLong(-1);  // 4294967295
```

## 七、常见陷阱

### 1. 整数除法截断

```java
System.out.println(5 / 2);     // 2  ⚠️ 整数除法，舍弃小数
System.out.println(5 / 2.0);   // 2.5  ✅ 至少一个是浮点数
System.out.println(5.0 / 2);   // 2.5  ✅
```

### 2. 强制转换不是四舍五入

```java
double d = 3.99;
int i = (int) d;        // 3  ⚠️ 直接截断
int r = (int) Math.round(d);  // 4  ✅ 四舍五入
```

### 3. 符号扩展与零扩展

```java
// 负数转大类型：符号扩展（高位补 1）
byte negative = -1;     // 二进制：11111111
int extended = negative; // 11111111 11111111 11111111 11111111 = -1

// char 转 int：零扩展（高位补 0）
char c = 'A';           // 二进制：00000000 01000001
int code = c;           // 00000000 00000000 00000000 01000001 = 65
```

### 4. 浮点数比较的精度问题

```java
double a = 0.1 + 0.2;
double b = 0.3;
System.out.println(a == b);  // false  ❌

// ✅ 使用误差范围
System.out.println(Math.abs(a - b) < 1e-10);  // true

// ✅ 使用 BigDecimal
BigDecimal bd1 = new BigDecimal("0.1").add(new BigDecimal("0.2"));
BigDecimal bd2 = new BigDecimal("0.3");
System.out.println(bd1.compareTo(bd2) == 0);   // true
```

## 八、类型转换速查表

```
         byte  short  char   int   long  float  double  boolean
byte      -     自动    ×    自动   自动   自动    自动      ×
short    强制    -     ×    自动   自动   自动    自动      ×
char     强制   强制    -    自动   自动   自动    自动      ×
int      强制   强制   强制    -    自动   自动    自动      ×
long     强制   强制   强制   强制    -    自动    自动      ×
float    强制   强制   强制   强制   强制    -      自动      ×
double   强制   强制   强制   强制   强制   强制     -       ×
boolean   ×     ×      ×     ×      ×      ×       ×       -
```

> 说明："自动"表示可以隐式转换，"强制"表示需要显式强转，"×"表示不兼容。

## 九、总结

- **小转大自动，大转小强制**：`byte → int` 自动，`int → byte` 强制
- **`char` 是整数**：可自动转 `int`，参与运算自动提升为 `int`
- **`byte/short/char` 运算结果是 `int`**：这是高频考点
- **浮点转整数直接截断**：不是四舍五入
- **溢出不报错**：大转小可能溢出，需要自行检测
- **字符串解析可能抛异常**：使用 `parseXxx()` 要注意格式校验

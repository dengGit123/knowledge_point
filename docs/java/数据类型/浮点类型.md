# 浮点类型（float / double）

> 📖 [Java Language Specification — Floating-Point Types, Formats, and Values](https://docs.oracle.com/javase/specs/jls/se17/html/jls-4.html#jls-4.2.3)

## 一、概述

Java 提供了 **2 种浮点类型**，用于存储带小数的数值，遵循 **IEEE 754** 标准：

| 类型 | 内存占用 | 有效数字（精度） | 取值范围（近似） | 默认值 |
| --- | --- | --- | --- | --- |
| `float` | 4 字节（32 bit） | 约 6~7 位十进制 | ±3.4028235E+38 | `0.0f` |
| `double` | 8 字节（64 bit） | 约 15~16 位十进制 | ±1.7976931348623157E+308 | `0.0d` |

> 💡 **快速记忆：** `double` 的精度是 `float` 的两倍多，是**默认的浮点类型**，日常编程几乎都用 `double`。

## 二、各类型详解

### 1. float（单精度浮点）

**作用**：在**内存敏感**的场景下存储小数，如大量浮点数的数组（3D 图形坐标、科学计算数据）。

```java
float pi = 3.14159f;       // 必须加 f 或 F 后缀
float temperature = 36.5f;
float ratio = 1.0f / 3.0f; // 0.33333334（约 7 位有效数字）
```

**特点**：

- 字面量必须加 `f` 或 `F` 后缀
- 精度有限，**不适合精确计算**

**注意事项**：

> ⚠️ **不能用于精确计算**：

```java
float a = 0.1f;
float b = 0.2f;
System.out.println(a + b);  // 0.30000002  ⚠️ 存在微小误差
```

> ⚠️ **与 double 不兼容**：

```java
// float f = 3.14;          // ❌ 编译错误：不兼容的类型
float f = 3.14f;            // ✅ 必须加 f
double d = 3.14;            // ✅ 默认是 double
```

### 2. double（双精度浮点）⭐ 最常用

**作用**：**默认的浮点类型**，日常编程中存储小数的首选。

```java
double pi = 3.141592653589793;
double distance = 1.5e11;      // 科学计数法：1.5 × 10¹¹（地球到太阳距离，米）
double avogadro = 6.022e23;    // 阿伏伽德罗常数
```

**特点**：

- 字面量默认就是 `double` 类型（无需后缀）
- 精度约 15~16 位有效数字，大多数场景够用
- 仍然是**近似表示**，不适用于需要绝对精确的场景

**注意事项**：

> ⚠️ **同样存在精度问题**：

```java
System.out.println(0.1 + 0.2);  // 0.30000000000000004  ⚠️ 不是精确的 0.3
System.out.println(1.0 - 0.9);  // 0.09999999999999998   ⚠️ 不是 0.1
```

## 三、IEEE 754 特殊值

浮点数有几个特殊值，整数类型不存在这些：

```java
// 正无穷大
double inf = Double.POSITIVE_INFINITY;  // Infinity
System.out.println(1.0 / 0.0);          // Infinity

// 负无穷大
double negInf = Double.NEGATIVE_INFINITY; // Infinity
System.out.println(-1.0 / 0.0);          // -Infinity

// 非数字（Not a Number）
double nan = Double.NaN;
System.out.println(0.0 / 0.0);           // NaN
System.out.println(Math.sqrt(-1));       // NaN
```

> ⚠️ **NaN 的比较规则**：NaN 与任何值（包括自身）比较都返回 `false`：

```java
double nan = Double.NaN;
System.out.println(nan == nan);         // false  ⚠️
System.out.println(nan != nan);         // true   ⚠️ NaN 的特性

// 正确判断方式
System.out.println(Double.isNaN(nan));   // true   ✅
```

## 四、精度问题与解决方案

### 为什么浮点数不精确？

计算机用二进制存储小数，很多十进制小数（如 0.1）在二进制下是**无限循环小数**，只能截断存储：

```
十进制 0.1 → 二进制 0.0001100110011...（无限循环）
```

### 解决方案：BigDecimal

涉及**金额、税率、科学精确计算**时，应使用 `BigDecimal`：

```java
import java.math.BigDecimal;

// ❌ 错误：用 double 构造 BigDecimal（会带入精度误差）
BigDecimal wrong = new BigDecimal(0.1);
System.out.println(wrong);  // 0.1000000000000000055511151231257827021181583404541015625

// ✅ 正确：用字符串构造 BigDecimal
BigDecimal right = new BigDecimal("0.1");
System.out.println(right);  // 0.1

// BigDecimal 运算
BigDecimal a = new BigDecimal("0.1");
BigDecimal b = new BigDecimal("0.2");
BigDecimal sum = a.add(b);
System.out.println(sum);            // 0.3
System.out.println(sum.equals(new BigDecimal("0.3"))); // true

// 除法必须指定精度和舍入模式
BigDecimal result = new BigDecimal("10").divide(new BigDecimal("3"), 4, BigDecimal.ROUND_HALF_UP);
System.out.println(result);  // 3.3333
```

## 五、浮点数比较

由于精度误差，直接用 `==` 比较浮点数是**危险**的：

```java
double a = 0.1 + 0.2;
double b = 0.3;

System.out.println(a == b);  // false  ❌ 不可靠

// ✅ 方法一：允许误差范围（epsilon）
double epsilon = 1e-10;
System.out.println(Math.abs(a - b) < epsilon);  // true

// ✅ 方法二：使用 BigDecimal
BigDecimal bd1 = new BigDecimal(Double.toString(a));
BigDecimal bd2 = new BigDecimal(Double.toString(b));
System.out.println(bd1.compareTo(bd2) == 0);     // true
```

## 六、类型转换规则

```java
// ✅ 自动转换：float → double（范围扩大，安全）
float f = 3.14f;
double d = f;   // 隐式转换，没问题

// ❌ 强制转换：double → float（可能损失精度）
double d2 = 3.141592653589793;
float f2 = (float) d2;  // 必须强制转换，精度从 15 位降到 7 位

// 整数 → 浮点：自动转换
int i = 100;
double d3 = i;  // 100.0，自动转换

// 浮点 → 整数：强制转换，直接截断小数
double d4 = 3.99;
int i2 = (int) d4;  // 3  ⚠️ 不是四舍五入，直接截断
int i3 = (int) Math.round(d4);  // 4  ✅ 四舍五入
```

## 七、实际应用场景

| 场景 | 推荐类型 | 说明 |
| --- | --- | --- |
| 日常小数计算 | `double` | 默认选择 |
| 大量浮点数组 | `float` | 节省内存（如 3D 顶点坐标） |
| 金额、税率 | `BigDecimal` | 必须精确，不能用浮点 |
| 科学计算 | `double` | 精度要求高 |
| 距离、温度 | `double` | 通用物理量 |

## 八、常用工具方法

```java
// 判断特殊值
Double.isInfinite(d);   // 是否无穷大
Double.isNaN(d);        // 是否 NaN
Double.isFinite(d);     // 是否有限数（非无穷非 NaN）

// 字符串转换
double parsed = Double.parseDouble("3.14");
String str = Double.toString(3.14);
String hex = Double.toHexString(0.1);  // 精确的十六进制表示

// 比较大小
Double.compare(0.1 + 0.2, 0.3);  // 返回 0（相等）、正数或负数
```

## 九、常见陷阱

### 1. 浮点 → 整数的截断

```java
double d = 3.9;
int i = (int) d;          // 3  ⚠️ 不是 4，直接截断
long l = Math.round(d);   // 4  ✅ 四舍五入
```

### 2. 金融计算不能用浮点

```java
// ❌ 错误示范
double total = 0.1 + 0.2;
if (total == 0.3) {  // false！条件不成立
    System.out.println("相等");
}

// ✅ 正确做法
BigDecimal total2 = new BigDecimal("0.1").add(new BigDecimal("0.2"));
if (total2.compareTo(new BigDecimal("0.3")) == 0) {
    System.out.println("相等");  // 输出
}
```

### 3. float 字面量后缀

```java
// float f = 3.14;   // ❌ 编译错误
float f = 3.14f;     // ✅
float f2 = 3.14F;    // ✅ 大写也可以
```

## 十、总结

- **`double` 是默认选择**：日常小数计算都用 `double`
- **`float` 用于内存敏感场景**：大量浮点数据时节省空间
- **浮点数不精确**：二进制无法精确表示 0.1 等小数
- **精确计算用 `BigDecimal`**：金额、税率等场景
- **比较用误差范围**：不要直接用 `==` 比较浮点数
- **特殊值要处理**：`Infinity` 和 `NaN` 需要特殊判断

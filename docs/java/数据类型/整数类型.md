# 整数类型（byte / short / int / long）

> 📖 [Java Language Specification — Integral Types and Values](https://docs.oracle.com/javase/specs/jls/se17/html/jls-4.html#jls-4.2.1)

## 一、概述

Java 提供了 **4 种整数类型**，用于存储不带小数的数值。它们都采用**二进制补码**表示，区别仅在于占用内存大小和取值范围：

| 类型 | 内存占用 | 位数 | 取值范围 | 默认值 |
| --- | --- | --- | --- | --- |
| `byte` | 1 字节 | 8 bit | -128 ~ 127 | `0` |
| `short` | 2 字节 | 16 bit | -32,768 ~ 32,767 | `0` |
| `int` | 4 字节 | 32 bit | -2,147,483,648 ~ 2,147,483,647 | `0` |
| `long` | 8 字节 | 64 bit | -9,223,372,036,854,775,808 ~ 9,223,372,036,854,775,807 | `0L` |

> 💡 **快速记忆：** 每种类型范围大约是下一种的 1/65536（即 2¹⁶ 分之一）。

## 二、各类型详解

### 1. byte（字节型）

**作用**：最小的整数类型，主要用于**节省内存**的场景，如处理原始二进制数据、文件 I/O 流。

```java
byte b1 = 100;           // 正常赋值
byte b2 = -128;          // 最小值
byte b3 = 127;           // 最大值
// byte b4 = 128;        // ❌ 编译错误：超出 byte 范围
```

**特点**：

- 只有 1 字节，是 Java 中最小的数据类型
- 取值范围只有 256 个值（-128 ~ 127）
- 在数组场景下节省内存效果显著

**注意事项**：

> ⚠️ **运算时自动提升为 int**：`byte` 参与算术运算时，结果会**自动提升为 `int`**，直接赋值回 `byte` 会编译失败：

```java
byte a = 1;
byte b = 2;
// byte c = a + b;       // ❌ 编译错误：不兼容的类型（int → byte 可能损失精度）
byte c = (byte) (a + b); // ✅ 必须强制转换
```

### 2. short（短整型）

**作用**：早期用于节省内存的整数类型，现代 Java 中**使用较少**，偶尔用于兼容旧 API。

```java
short s1 = 1000;
short s2 = -32768;       // 最小值
short s3 = 32767;        // 最大值
```

**特点**：

- 2 字节，范围比 `byte` 大很多
- 与 `byte` 一样，运算时自动提升为 `int`

**注意事项**：

> ⚠️ **几乎被 int 取代**：现代 JVM 中，`short` 和 `int` 的运算效率几乎相同，`int` 是默认选择。除非处理**已知范围的小整数数组**，否则优先用 `int`。

### 3. int（整型）⭐ 最常用

**作用**：**默认的整数类型**，日常编程中使用最广泛。

```java
int age = 25;
int count = 1_000_000;   // 下划线分隔，提高可读性
int color = 0xFF00FF;    // 十六进制表示颜色
int binary = 0b101010;   // 二进制表示
```

**特点**：

- 4 字节，范围约 ±21 亿，覆盖绝大多数业务场景
- JVM 对 `int` 的运算做了大量优化，**效率最高**
- 是数组索引、循环计数器的默认类型

**注意事项**：

```java
// ⚠️ 溢出不会报错
int max = Integer.MAX_VALUE;  // 2147483647
System.out.println(max + 1);  // -2147483648  ❌ 变成最小值

// ⚠️ 大数字面量必须加 L，否则编译错误
// int big = 3000000000;     // ❌ 超出 int 范围
long big = 3000000000L;      // ✅ 加 L 表示 long 字面量

// ⚠️ 整数除法截断
System.out.println(5 / 2);   // 2  ❌ 不是 2.5
System.out.println(5 / 2.0); // 2.5  ✅ 至少一个是浮点数
```

### 4. long（长整型）

**作用**：存储超过 `int` 范围的大整数，常用于**时间戳、全局唯一 ID、大文件尺寸**等场景。

```java
long timestamp = System.currentTimeMillis();  // 时间戳（毫秒）
long fileSize = 3_500_000_000L;               // 3.5GB 的文件大小
long id = 9223372036854775807L;               // 最大值
```

**特点**：

- 8 字节，范围约 ±922 亿亿
- 字面量必须加 `L` 后缀（建议大写，小写 `l` 容易与数字 `1` 混淆）

**注意事项**：

> ⚠️ **字面量必须加 L**：

```java
// long wrong = 3000000000;  // ❌ 编译错误：整数太大，超出 int 范围
long right = 3000000000L;    // ✅ 加 L 表示这是 long 类型字面量
```

> ⚠️ **多线程下的可见性**：`long` 和 `double` 的写入在 32 位 JVM 上**不是原子操作**（分两次 32 位写入）。多线程共享的 `long` 变量应加 `volatile` 或使用 `AtomicLong`：

```java
private volatile long counter = 0L;  // ✅ 保证原子写入
```

## 三、字面量进制表示

Java 支持四种进制书写整数字面量：

```java
int decimal = 26;         // 十进制 → 26
int hex = 0x1A;           // 十六进制（前缀 0x）→ 26
int binary = 0b11010;     // 二进制（前缀 0b）→ 26
int octal = 032;          // 八进制（前缀 0）→ 26

System.out.println(decimal == hex);     // true
System.out.println(decimal == binary);  // true
System.out.println(decimal == octal);   // true
```

> 💡 **常见用途：**
> - **十六进制**：表示颜色（`0xFF5733`）、掩码（`0xFF`）
> - **二进制**：位运算场景（`0b1010`）、标志位

## 四、取值范围常量

每种整数类型都提供了对应的常量字段，方便获取边界值：

```java
System.out.println(Byte.MIN_VALUE);    // -128
System.out.println(Byte.MAX_VALUE);    // 127
System.out.println(Short.MIN_VALUE);   // -32768
System.out.println(Short.MAX_VALUE);   // 32767
System.out.println(Integer.MIN_VALUE); // -2147483648
System.out.println(Integer.MAX_VALUE); // 2147483647
System.out.println(Long.MIN_VALUE);    // -9223372036854775808
System.out.println(Long.MAX_VALUE);    // 9223372036854775807
```

## 五、溢出检测

整数溢出不会抛异常，需要手动检测：

```java
// 使用 Math 的精确方法（Java 8+），溢出时抛出 ArithmeticException
int safe = Math.addExact(Integer.MAX_VALUE, 1);  // 抛出异常 ✅
int safe2 = Math.multiplyExact(100000, 100000);  // 抛出异常 ✅
```

## 六、各类型运算规则

| 运算场景 | 结果类型 |
| --- | --- |
| `byte` `short` `char` 之间运算 | 自动提升为 `int` |
| `int` 与 `int` 运算 | `int` |
| 任意操作数为 `long` | `long` |
| 有 `long` 参与 | 整体提升为 `long` |

```java
byte b = 1;
short s = 2;
int i = 3;
long l = 4L;

// byte + short → int
// byte result = b + s;     // ❌ 编译错误
int intResult = b + s;      // ✅ 结果是 int

// int + long → long
long longResult = i + l;    // ✅ 结果是 long
```

## 七、实际应用场景

| 场景 | 推荐类型 | 示例 |
| --- | --- | --- |
| 年龄、数量 | `int` | `int age = 25;` |
| 时间戳 | `long` | `long now = System.currentTimeMillis();` |
| 文件字节数据 | `byte[]` | `byte[] buffer = new byte[1024];` |
| 位标志/掩码 | `int` | `int FLAG_READ = 0b0001;` |
| 大文件尺寸 | `long` | `long size = file.length();` |
| 循环计数器 | `int` | `for (int i = 0; i `` 10; i++)` |

## 八、常见陷阱

### 1. 包装类缓存池

`Integer` 缓存了 **-128 ~ 127** 的对象，此范围内 `==` 比较返回 `true`：

```java
Integer a = 127;
Integer b = 127;
System.out.println(a == b);     // true  （同一缓存对象）

Integer c = 200;
Integer d = 200;
System.out.println(c == d);     // false （不同对象）
System.out.println(c.equals(d)); // true  （值相等）
```

> 包装类比较请始终使用 `equals()`。详见 [包装类型.md](./包装类型.md)。

### 2. 无符号处理

Java 没有无符号整数类型（C 语言有 `unsigned int`），但 Java 8 在包装类中提供了无符号操作方法：

```java
int signed = -1;
// 将 int 当作无符号数解析，结果为 4294967295
long unsigned = Integer.toUnsignedLong(signed);
String str = Integer.toUnsignedString(signed);  // "4294967295"
```

## 九、总结

- **`int` 是默认选择**：90% 的整数场景用 `int` 就够了
- **`long` 处理大数**：时间戳、大 ID、文件尺寸
- **`byte` 处理二进制**：I/O 流、网络协议
- **`short` 少用**：现代 JVM 中优势不明显
- **注意溢出**：溢出不报错，大数运算用 `Math.xxxExact()` 检测
- **`long` 字面量加 L`：避免被当作 int 导致编译错误

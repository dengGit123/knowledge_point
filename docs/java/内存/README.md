### 一、这个系列讲什么

Java 程序为什么不需要手动 `free` 内存？`new` 一个对象到底发生了什么？静态代码块为什么只执行一次？OOM 了怎么排查？——所有答案都藏在 **JVM 的内存体系**里。

本系列从"内存怎么分区"讲到"对象怎么生灭"，再到"垃圾怎么回收、问题怎么排查"，构成一条完整的学习路径：

```
 内存分区（地基）          对象与类（主体）           回收与实战（进阶）
┌─────────────────┐   ┌─────────────────────┐   ┌──────────────────────┐
│ 01 区域总览       │   │ 04 实例与静态成员     │   │ 10 垃圾回收           │
│ 02 程序计数器     │ → │ 07 类加载机制         │ → │ 11 内存溢出与泄漏排查  │
│ 03 虚拟机栈与栈帧 │   │ 08 对象在内存中       │   │                      │
│ 05 堆            │   │ 09 代码块与初始化顺序  │   │                      │
│ 06 方法区        │   │                     │   │                      │
└─────────────────┘   └─────────────────────┘   └──────────────────────┘
```

### 三、核心概念速查

| 概念 | 一句话解释 | 详见 |
|------|-----------|------|
| **堆（Heap）** | 所有 `new` 出来的对象的家，GC 主战场，线程共享 | [05](./05-堆.md) |
| **虚拟机栈（VM Stack）** | 方法调用的"盘子摞"，局部变量所在地，线程私有 | [03](./03-虚拟机栈与栈帧.md) |
| **方法区（Method Area）** | 类的"图纸资料室"，JDK 8+ 由元空间（本地内存）实现 | [06](./06-方法区.md) |
| **程序计数器（PC）** | 线程的"书签"，记录执行到哪条字节码 | [02](./02-程序计数器.md) |
| **实例成员 vs 静态成员** | 随对象生灭每对象一份 vs 随类生灭全类一份（无 this） | [04](./04-实例与静态成员.md) |
| **栈帧（Stack Frame）** | 一次方法调用的私有工作区（局部变量表 + 操作数栈） | [03](./03-虚拟机栈与栈帧.md) |
| **元空间（Metaspace）** | JDK 8+ 方法区的实现，使用本地内存，取代永久代 | [06](./06-方法区.md) |
| **GC Roots** | 可达性分析的起点：栈中变量、静态变量、常量、Native 引用 | [10](./10-垃圾回收.md) |
| **Minor GC / Full GC** | 新生代回收（快而频）/ 整堆回收（慢而少） | [10](./10-垃圾回收.md) |
| **TLAB** | Eden 里的线程私有分配缓冲区，让 `new` 免锁提速 | [05](./05-堆.md) |
| **双亲委派** | 类加载先委派父加载器，保证核心类安全、类不重复 | [07](./07-类加载机制.md) |

### 五、学习建议

1. **先打地基**：从 [01 总览](./01-JVM内存区域总览.md) 建立全局地图，再逐个深入各区域文档；
2. **抓住主线**：整条主线是"**一个对象的一生**"——它在堆中如何诞生（08）、如何被引用（08/03）、如何晋升（05）、如何被回收（10）；
3. **结合代码验证理解**：每篇文档的示例都可以自己在 IDE 里跑一跑（如 `-Xss` 调小复现 StackOverflow、`jstat` 观察分代变化）；
4. **面试导向**：每篇结尾的"总结"表格 + "记住三句话"就是核心考点速记卡；
5. **延伸阅读**：GC 参数与调优实战见 [../JVM调优.md](../JVM调优.md)；反射与 `Class` 对象见 [../反射.md](../反射.md)；多线程与内存可见性（JMM）见 [../多线程/](../多线程/线程相关概念.md)。

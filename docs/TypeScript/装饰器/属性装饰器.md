# 属性装饰器（Property Decorator）

## 一、定义

**属性装饰器**是应用于类属性的装饰器，在属性声明之前声明。属性装饰器可以用来**观察**属性的声明，但不能直接修改属性的值（因为属性装饰器没有属性描述符参数）。

## 二、基本语法

```typescript
/**
 * 属性装饰器参数：
 * @param target - 对于静态属性是类的构造函数，对于实例属性是类的原型
 * @param propertyKey - 属性名称
 */
function PropertyDecorator(target: any, propertyKey: string) {
  console.log(`属性装饰器被调用`);
  console.log('target:', target);
  console.log('propertyName:', propertyKey);
}

class User {
  @PropertyDecorator
  name: string;

  @PropertyDecorator
  age: number;

  constructor(name: string, age: number) {
    this.name = name;
    this.age = age;
  }
}
```

### 参数说明

| 参数 | 类型 | 说明 |
|-----|------|------|
| `target` | `any` | 实例属性 → 类的原型对象；静态属性 → 类的构造函数 |
| `propertyKey` | `string \| symbol` | 被装饰的属性名称 |

> **注意**：属性装饰器**只有两个参数**，没有第三个 `descriptor` 参数，因为属性装饰器应用于类字段声明，而不是对象字面量的属性。

## 三、属性装饰器的返回值

属性装饰器**不能返回任何值**（返回值会被忽略）。它的作用仅限于：
1. 观察属性的声明
2. 在原型上存储元数据
3. 使用 `Object.defineProperty` 定义属性

## 四、常见应用场景

### 1. 只读属性

```typescript
function ReadOnly(target: any, propertyKey: string) {
  Object.defineProperty(target, propertyKey, {
    writable: false,
    configurable: false
  });
}

class User {
  @ReadOnly
  id: number = 1;

  name: string = '默认';

  constructor(id: number, name: string) {
    this.id = id;
    this.name = name;
  }
}

const user = new User(1, 'Alice');
// user.id = 2; // 报错：Cannot assign to read only property 'id'
console.log(user.id); // 1
```

### 2. 默认值设置

```typescript
function DefaultValue(value: any) {
  return function (target: any, propertyKey: string) {
    // 设置默认值
    target[propertyKey] = value;
  };
}

class Config {
  @DefaultValue('localhost')
  host!: string;

  @DefaultValue(3000)
  port!: number;

  @DefaultValue(true)
  debug!: boolean;
}

const config = new Config();
console.log(config.host); // "localhost"
console.log(config.port); // 3000
console.log(config.debug); // true
```

### 3. 格式化转换

```typescript
function Format(formatString: string) {
  return function (target: any, propertyKey: string) {
    let value: string = '';

    Object.defineProperty(target, propertyKey, {
      get() {
        return value;
      },
      set(newValue: string) {
        if (formatString === 'uppercase') {
          value = newValue.toUpperCase();
        } else if (formatString === 'lowercase') {
          value = newValue.toLowerCase();
        } else if (formatString === 'trim') {
          value = newValue.trim();
        } else {
          value = newValue;
        }
      },
      enumerable: true,
      configurable: true
    });
  };
}

class User {
  @Format('uppercase')
  name!: string;

  @Format('trim')
  email!: string;
}

const user = new User();
user.name = 'alice';
user.email = '  ALICE@EXAMPLE.COM  ';

console.log(user.name); // "ALICE"（自动大写）
console.log(user.email); // "ALICE@EXAMPLE.COM"（自动去空格）
```

### 4. 验证装饰器

```typescript
function MinLength(min: number) {
  return function (target: any, propertyKey: string) {
    let value: string = '';

    const setter = (newValue: string) => {
      if (newValue.length < min) {
        throw new Error(`${propertyKey} 长度不能少于 ${min} 个字符`);
      }
      value = newValue;
    };

    const getter = () => value;

    Object.defineProperty(target, propertyKey, {
      get: getter,
      set: setter,
      enumerable: true,
      configurable: true
    });
  };
}

function MaxLength(max: number) {
  return function (target: any, propertyKey: string) {
    let value: string = '';

    const setter = (newValue: string) => {
      if (newValue.length > max) {
        throw new Error(`${propertyKey} 长度不能超过 ${max} 个字符`);
      }
      value = newValue;
    };

    const getter = () => value;

    Object.defineProperty(target, propertyKey, {
      get: getter,
      set: setter,
      enumerable: true,
      configurable: true
    });
  };
}

class User {
  @MinLength(3)
  @MaxLength(20)
  username!: string;

  @MinLength(6)
  password!: string;
}

const user = new User();
user.username = 'Alice'; // OK
// user.username = 'AB'; // 报错：长度不能少于 3 个字符
```

### 5. 日志追踪

```typescript
function LogChanges(target: any, propertyKey: string) {
  let value: any = undefined;

  const getter = () => value;
  const setter = (newValue: any) => {
    console.log(`[属性变化] ${propertyKey}: ${value} → ${newValue}`);
    value = newValue;
  };

  Object.defineProperty(target, propertyKey, {
    get: getter,
    set: setter,
    enumerable: true,
    configurable: true
  });
}

class State {
  @LogChanges
  count: number = 0;

  @LogChanges
  status: string = 'idle';
}

const state = new State();
state.count = 1; // [属性变化] count: undefined → 1
state.count = 2; // [属性变化] count: 1 → 2
state.status = 'loading'; // [属性变化] status: idle → loading
```

### 6. 存储元数据

```typescript
// 简单的元数据存储
const metadataStore = new WeakMap<object, Map<string, any>>();

function Metadata(meta: { type: string; required?: boolean }) {
  return function (target: any, propertyKey: string) {
    // 获取或创建存储
    let metaMap = metadataStore.get(target);
    if (!metaMap) {
      metaMap = new Map();
      metadataStore.set(target, metaMap);
    }

    // 存储元数据
    metaMap.set(propertyKey, {
      ...meta,
      name: propertyKey
    });

    // 同时存储到构造函数原型上
    if (!target.constructor._propertyMetadata) {
      target.constructor._propertyMetadata = [];
    }
    target.constructor._propertyMetadata.push({
      property: propertyKey,
      ...meta
    });
  };
}

class User {
  @Metadata({ type: 'string', required: true })
  name!: string;

  @Metadata({ type: 'number', required: false })
  age!: number;

  @Metadata({ type: 'email', required: true })
  email!: string;
}

// 获取元数据
console.log(User._propertyMetadata);
// [
//   { property: 'name', type: 'string', required: true },
//   { property: 'age', type: 'number', required: false },
//   { property: 'email', type: 'email', required: true }
// ]
```

## 五、属性装饰器的局限性

### 1. 无法直接访问实例属性

属性装饰器在类原型上操作，**无法直接访问实例属性**的值：

```typescript
class User {
  @LogProperty
  name: string = '默认值'; // 装饰器无法访问这个 '默认值'
}

function LogProperty(target: any, propertyKey: string) {
  // 这里的 target 是 User.prototype，不是实例
  console.log(target[propertyKey]); // undefined（原型上没有这个值）
}
```

### 2. 需要配合 getter/setter

如果想在属性赋值时执行逻辑，需要使用 `Object.defineProperty` 定义 getter/setter：

```typescript
function TrackChanges(target: any, propertyKey: string) {
  let value: any;

  Object.defineProperty(target, propertyKey, {
    get() {
      return value;
    },
    set(newValue: any) {
      console.log(`${propertyKey} 被设置为:`, newValue);
      value = newValue;
    },
    enumerable: true,
    configurable: true
  });
}
```

### 3. 与 TypeScript 编译器的交互

使用 `useDefineForClassFields` 选项时，属性装饰器的行为可能受影响：

```json
// tsconfig.json
{
  "compilerOptions": {
    "useDefineForClassFields": false // 推荐设为 false 以兼容装饰器
  }
}
```

## 六、属性装饰器 vs 访问符装饰器

| 特性 | 属性装饰器 | 访问符装饰器 |
|-----|-----------|-------------|
| 参数个数 | 2 个（target, propertyKey） | 3 个（target, propertyKey, descriptor） |
| 属性描述符 | ❌ 没有 | ✅ 有 |
| 可修改属性 | ❌ 返回值被忽略 | ✅ 可返回新的 descriptor |
| 适用场景 | 存储元数据、定义 getter/setter | 修改已有 getter/setter 的行为 |
